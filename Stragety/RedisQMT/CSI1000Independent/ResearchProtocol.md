# 中证1000主板独立策略研究

建立日期：2026-10-27。目标：扣除成本后的连续账户年化收益 >100%，完整平仓交易净胜率 >60%。这是验收目标，当前没有达标证据。

最新用户约束（2026-10-27）：**Redis QMT为唯一数据源**，适用于行情、历史成分及公司行动；覆盖本文此前允许替代来源的安排。外部成分重建、TDX和本机原生SDK资料仅作既有研究档案，不再驱动后续研究。现有770候选依赖外部成分池，亦只能保留为旧诊断，不能称Redis唯一来源结果。恢复条件改为Redis自身提供有效历史成员及完整分钟行情；不要求用户另购或提供其他来源。外源读取入口已禁用，后续准备脚本在读取外源成分池时立即失败，不新增网络请求。

Redis路径追加核验：兼容客户端普通 `call()` 会优先尝试FormulaServer，配置 `transport_name=redis` 不能单独证明市场读取经过Redis。新增 `probe_redis_membership.py` 显式 `call_rpc()`，绕过FormulaServer；首次直接Redis查询2025-10-09、2025-12-15、2026-06-15均返回0，latest返回1000，原始请求/响应及连接信息见 `redis_rpc_membership.json`。此前普通板块查询的“Redis来源”称呼缺少逐请求路径证明，仅作旧诊断，不据此认证来源。分钟读取已有 `bypass_formula=True`，本轮未重查已知缺失分钟或补下载。

首次补下载实验追加（2026-10-27 17:18—17:20）：此前本研究所有历史行情检查都只有读取，没有补下载。因此“740个读取不合格会话”不能推导为“740个服务器无法补齐会话”。检查当前保留的Redis任务索引未发现603305.SH任务（索引有TTL，不证明全局从未下载），且本研究下载次数为0后，仅对603305.SH/2025-10-10做一次首次补下载；该代码在显式Redis latest响应中，不使用外部成分池选取此试验。

`check_first_redis_download.py` 经显式Redis提交任务130a1da2813b41c8，任务done=1/state=done，但即时分钟仍241行、正成交分钟0，OHLC及量额均与Redis日线不符。67秒后仅只读复核同一任务，分钟文件字节及SHA256完全相同，仍无有效分钟。原始状态、首次数据和延迟观察分别见 `first_redis_download/attempt.json`、`minutes.parquet`、`settled_observation.json`。没有第二次提交、正式回放或下单。这一会话现有明确的一次补下载后失败证据，后续不再重试；不能把单一试验推广成全部740个区间均不可补。

另按官方Python API p69首次显式Redis调用 `get_his_index_data('000852.SH')`，返回空字典；它与按日期板块查询是不同的历史指数入口，证据 `redis_historical_index_probe.json`。仍未取得可用历史成员。任务完成只证明下载命令处理完成，不证明服务端完成落盘或行情有效，不能据此更新有效分钟区间。

## 预先约定

- 股票池为交易当日有效中证1000成分，只允许沪深主板，排除科创板、创业板、ST及退市整理股票。不得以当前成分替代历史成员。
- 初始资金暂按100万元、空仓，不融资、不做空。每只上限20%，最多5只；后续资金假设变化须单列实验。
- 正式研究候选区间2025-10-10至2026-10-09，必须先核实有效分钟覆盖。此前日线仅用于预热和诊断。
- 开发段至2026-06-30，验证段2026-07-01至2026-10-09；后者只作一次冻结规则验证。已有其他策略使用过该区间，因此不称完全未见样本；真正前瞻验证从规则冻结后的下一交易日开始。
- 年化以完整账户含空仓日期和期末持仓市值计算；胜率按完整持仓从建仓至清仓的扣费盈亏统计，拆单和部分止盈不单独计胜。披露未平仓数和浮盈亏。
- 佣金暂按单边万三、每笔最低5元；卖出印花税和过户费按对应日期有效规则核验后冻结。基础单边滑点0.1%，压力0.3%，另做双倍佣金。不得省略T+1、停牌、涨跌停、整手和成交量约束。

## 首个假设：上升趋势中的缩量回撤再转强

先验证一个机制，不借用已有A144策略规则或版本文件。

1. 前日收盘后选股：收盘在MA20和MA60之上，MA20高于5日前；20日涨幅5%至30%；近3日回撤2%至8%；近3日均成交额低于这3日之前20日均值；20日均成交额不少于5000万元，至少120根有效日线作为上市时长的初筛代理，正式交易前仍需上市日期核验。
2. 按20日相对中证1000收益排序，每天仅保留前10只候选。指数前日收盘低于MA60时不开新仓。
3. 当日09:45后，用已结束分钟确认价格突破前15个完整分钟最高价且站上当日连续竞价截至该分钟VWAP（不含09:30集合竞价行）；下一分钟才尝试成交，最迟14:30停止开仓。每只每日只允许一次入场。
4. 建仓后从下一交易日开始允许卖出：止损5%、盈利8%后按最高已见价回撤3%退出、前日收盘跌破MA20退出，或持仓10交易日退出。信号在已结束分钟形成，下一分钟执行；无法成交则继续持有，不虚构止损成交。
5. 止损和跟踪价格需用可交易原价并正确处理公司行动；日线信号复权必须防止未来公司行动信息泄漏。

退出规则实现补充：`core/exits.py` 已实现完成分钟上的退出信号，建仓当日不卖；当日仍跟踪持仓后已见高点；持仓期限10个交易会话包含建仓会话。止损、前日MA20破位、期限、跟踪退出按此顺序判定。输出仅为信号，不含成交价，仍须后续有效分钟满足可卖和成交条件才成交。公司行动须先经调用方核验并映射持仓价格基准，未实现到账账本，不据单元测试宣称具备完整回放能力。

核查命令：`python -m unittest discover -s Stragety/RedisQMT/CSI1000Independent/tests -v`；共12项测试覆盖入场因果性、T+1、跳空只报信号、占位价拒绝及Redis来源限制。所有测试只使用合成输入，不能证明年化或胜率目标。

阈值为初始研究假设，并无有效性证据。若目标失败，保留失败结果，再逐项提出新假设；不能为了凑胜率延迟确认亏损，不能无限扫参数后把同一区间称样本外。
