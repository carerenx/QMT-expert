# A144 v4 候补替代回测报告

## 结论

本次 **5 分钟敏感性回测没有证明 v4 候补替代机制可投入实盘**。

按真实状态机修正重复计算后，原 v3 的 16 次强制/紧急回补事件只对应 5 个独立底仓周期。第一次候补替代完成后，原票和候补进入替代组，原票后续不应继续产生新的反 T 周期，因此不能把 16 次事件当作 16 个独立机会。

5 个底仓周期均在当天或下一交易日找到了候补：4 次当天尾盘替代，1 次次日开盘替代。4 次可以完成无除权干扰的配对估值，合计相对“不做反 T”增加 92,037.05 元，相对 v3 原票回补路径增加 99,821.32 元。然而，其中 688185.SH 单笔贡献 94,372.60 元，占可评估总增益的 102.54%。剔除该极端赢家后，剩余 3 次相对“不做反 T”合计 **亏损 2,335.55 元**。

因此，当前证据只能说明候补替代有机会避开原票追高，不能说明候补替代本身具有稳定正收益。v4 继续限定为观察模式，不通过无人值守实盘部署闸门。

## 回测口径

- 来源事件：v3 的 5 分钟扩大样本敏感性回放中，所有 `force-buyback` 和 `emergency-buyback` 事件。
- 独立事件：按 `股票 + 原始入场日 + 原定退出日` 去重，只保留每个底仓周期第一次坏回补事件。
- 候补信号：只使用替代日前一个完整交易日的数据；沿用当前 d12/r04 的 A144 排名、入场条件、市场过滤、冷却和持仓排除。
- 候补竞争：已经被其他替代腿占用的股票，在其原定退出日前不再重复分配。
- 执行价：当天匹配使用 14:55 起第一根 5 分钟线开盘价；隔夜等待使用下一可匹配日 09:35 第一根 5 分钟线开盘价。
- 仓位：使用原票卖出金额的 98%，同时受释放现金约束，向下取整到 100 股。
- 估值终点：候补与“不做反 T”的原票均估值到原底仓计划退出日开盘。
- 费用：买入 7.6bp；卖出按日期使用 12.6bp/17.6bp 口径。
- 限制：这是首次替代决策的配对回测，不是包含候补后续信号、账户复利和全部组合调仓的连续账户回测。

## 状态机口径修正

最初把 16 次坏回补逐次配对，会重复计算同一底仓。实际 v4 在第一次候补成交后会转移 A144 归属，并给原票残仓与候补设置相同的 `replacement_group`；组内两票并存时禁止再次做 T。

修正后的事件数如下：

| 口径 | 事件数 |
|---|---:|
| v3 强制/紧急回补记录 | 16 |
| 独立底仓周期 | 5 |
| 找到候补 | 5 |
| 当天找到 | 4 |
| 次日找到 | 1 |
| 可完整估值 | 4 |
| 跨除权期、暂不估值 | 1 |

| 指标 | 结果 |
|---|---:|
| 5 个首次坏回补事件的 v3 净贡献 | -9,852.19 元 |
| 4 个可评估事件的 v3 净贡献 | -7,784.27 元 |
| 4 个可评估事件的 v4 净贡献 | +92,037.05 元 |

| v4 相对不做 T 胜率 | 75.00%（3/4） |
| v4 优于 v3 比例 | 75.00%（3/4） |
| 单笔最大贡献 | +94,372.60 元 |

表面总收益为正，但结果由单一股票、单一短周期行情主导。剔除最大赢家后，替代机制虽然仍比 v3 的追回原票少亏 3,194.66 元，却没有跑赢“不做反 T”。这更接近“降低坏回补损失”，而不是已经验证的新 alpha。

## 风险与部署判断

1. 样本只有 5 个独立底仓周期、4 个可计价事件，无法估计稳定胜率、尾部损失和市场阶段适应性。
2. 数据集中在 2026 年 7—8 月，且股票池是当前成分股快照，存在阶段集中和生存者偏差。
3. 5 分钟执行粒度粗于实盘轮询，不能替代默认要求的严格 1 分钟回测。
4. 当前配对回测没有把候补持仓后续 A144 退出、组合资金竞争和复利路径全部反馈到账户。
5. 603719.SH 单笔相对不做 T 亏损 20,611.77 元，说明“换票”只是把原票趋势风险转换为横截面选股风险，并未消除风险。

部署结论：**不启用 live，只保留 signal/观察模式**。后续至少需要历史成分股、跨市场阶段、严格 1 分钟数据和不少于 100 个独立替代周期；同时报告剔除前 1/5/10 个赢家后的收益，才能判断候补替代是否稳定有效。
