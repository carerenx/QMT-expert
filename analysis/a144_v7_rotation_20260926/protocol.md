# A144 v7 横截面趋势轮动预注册方案

登记时间：2026-09-26；结果产生前登记。

前两轮v5/v6失败的共同特征是平均股票暴露约28%—32%。本轮检验一个新机制：
当市场状态允许时，固定周期持有横截面趋势最强的一组股票；状态关闭时转为现金。
不使用反T、候补追回、融资或杠杆。

数据仅来自RedisQMT桥接及此前由该桥接冻结的日线OHLCV。
当前中证500快照导致生存者偏差，因此结果只用于机制筛选，不能直接作为实盘收益声明。

训练区间2022-01-04—2024-12-31。验证区间2025-01-02—2026-09-18，
选择完成后不根据验证期更换候选。初始资金100万元，用户允许最大回撤35%。
主目标为连续账户年化超过36%；选择规则为训练期回撤不超过35%后，取年化/回撤比最高者。

固定六组候选：

1. 60日动量前5，5日轮动，指数高于120日均线；
2. 120日动量前5，5日轮动，指数高于120日均线；
3. 60/120日动量与趋势效率复合前5，5日轮动；
4. 同一复合分数前5，10日轮动；
5. 同一复合分数前10，10日轮动；
6. 复合前5，5日轮动，并要求市场宽度不低于45%。

所有因子只使用信号日收盘前的已完成日线，次日开盘执行。候选必须上市至少130个交易日、
20日平均成交额不低于3000万元、收盘高于50日均线、60日动量为正、ATR比例在1%—8%。
每次轮动先卖出旧组合，再等权买入目标；整手交易，科创板首次买入至少200股。
单次买入不超过信号日20日均成交额的0.1%。

费用：买7.6bp；卖2023-08-28前17.6bp、之后12.6bp；每笔最低5元。
开盘触及保守涨跌停阈值时不成交，失败委托不使用当日收盘价替代。
持仓缺日线冻结最近估值并计数。

若日线预筛通过，才用RedisQMT真实1分钟数据按09:32开盘价复核。
任何目标证券交易日少于240根正价格分钟线，正式验证直接阻断，不回退到日线或其他来源。
