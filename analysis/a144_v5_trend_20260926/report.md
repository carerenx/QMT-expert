# A144 创新研究：未达到36%年化目标

2026-09-26。约束：数据仅来自RedisQMT桥接；不加杠杆；100万元研究账户；用户允许最大回撤35%。

## 结论

完成v4入口及其配置、信号模型、运行时、既有研究引擎的阅读；新建两个独立研究版本，
检验10组预先固定的方案。**本轮没有找到达到36%年化目标的策略，也没有上线新策略。**
v5、v6均未超过本轮重建对照，保留为失败研究，不标记最佳版本。

严格1分钟回放在数据完整性检查阶段阻断，以下收益均为**日线预筛结果**。
不能将其描述为已完成正式分钟回测，也不能把现有代码描述为可直接实盘的完整交易系统。

## 从v4得到的判断

`A144_v4_CandidateReplacement.py`本身只是入口，真正逻辑位于配置、model和runtime。
它的日线主体按下跌流动性冲击排名、突破及质量过滤入场，最多5仓，正常20日退出；
弱势退出可保留槽位，亏损后长期冷却。反T和候补替代目前生产关闭。

既有记录中的17.56%年化属于旧研究口径；旧反T分钟回放代码明确使用新浪缓存，
不符合本次唯一数据源限制。本轮没有使用那些分钟数据。

旧`analysis/research_a144_redisqmt.py`在开盘买入时读取成交日完整日线的ATR/振幅进行仓位计算，
存在前视；持仓缺行时也会漏计市值。本轮另建引擎：风险预算冻结在信号日，缺行冻结最近估值，
不修改旧实验文件或现有v4实盘逻辑。

## 两个新版本

- `A144_v5_TrendPersistence.py`：突破与缩量回踩双入口，相对强度及趋势效率排序；
  取消固定20日到期，采用4ATR移动退出、趋势破坏退出和10%收盘硬止损。
  训练期从6组中选择“宽移动退出”，风险预算1.5%，单票不超过20%。
- `A144_v6_LeadershipRotation.py`：直接参与60日相对强度前5%的领先股；排名跌出前15%退出，
  配合指数60日均线过滤、5ATR退出和3%风险预算。训练期从4组中选择严格市场过滤版。

两者仅导入公共core，不导入同级旧策略。入口提供完成日的只读候选扫描；
账户持仓归属、委托与部分成交处理未接入，因此没有live/execute模式。
核心入场与退出函数同时用于研究回放，测试覆盖因果性和主要成交约束。

## 分钟证据与缺口

通过`get_market_data_ex(... period="1m", dividend_type="none", fill_data=False,
bypass_formula=True)`直接读取Redis RPC。接口依据为仓库
`integrations/bigqmt/src/bigqmt_signal_trader/xtquant_compat.py`，属于自定义桥接接口。
下载补充使用该适配层已实现的`download_history_data2` RPC。

补充下载后，600329.SH与603868.SH请求区间内各返回275,463行时间戳，
但只有57,250行价格为正，第一条有效数据为2025-09-25 11:18。
601869.SH同区间有效60,250行，第一条为2025-09-09 09:30。
300776.SZ在2022-01-05目标成交日也是0/240有效分钟。
有时间戳不代表有行情；`fill_data=False`仍返回占位，必须检查价格。

正式成交口径预设为前一交易日收盘信号、次日09:32分钟线开盘执行，
收盘使用15:00分钟价。每个访问到的持仓/交易日要求240根有效连续交易时段分钟线；
缺失、全零或与日线价格不一致即阻断，绝不回退为日线或其他供应商价格。
结果见`validation.json`和`leader_validation.json`：完整区间正式验证均未通过数据闸门。

## 仍然存在的研究限制

- 股票池是本轮桥接取得的当前中证500快照，存在生存者偏差。
- 仅使用原桥接面板的OHLCV及复权价格，不使用旧面板外部来源的退市名单等元数据。
  历史ST状态缺失；主板开盘涨跌接近4.8%即保守阻止相应买卖，科技板按19.5%阈值。
  这不是精确历史涨跌停模型，未模拟停板队列。
- 原始价格整手买入，科创板最低200股；随后使用复权单位跟踪经济权益。
  公司行动没有逐笔现金/送股/税费账本，跨除权退出数量是近似，不能用于实盘下单。
- 成本买7.6bp、卖12.6bp（2023-08-28前17.6bp），每笔最低5元；是包含滑点的研究假定。
  资金上限另限于前一完成日可知的20日均成交额的0.1%；未模拟分钟盘口容量和成交冲击。
- 收盘硬止损在下一可交易时点执行，跳空和停牌可能超过止损；35%是筛选条件，不是风险保证。
- v5有1个持仓日缺日线，按最近估值冻结并计数；完整分钟与公司行动验证前不得宣称达标。

## 复现

冻结输入：`analysis/panel_20260920/panel.parquet`，本目录的`universe.json`、`benchmark_1d.parquet`。
新机器缺少该冻结面板时需要从RedisQMT重新构建，不能以其他来源替代。
输入SHA-256校验和见`inputs_manifest.json`；已落盘分钟覆盖统计见`minute_coverage.json`。
`prepare`会重新冻结当前池和指数；原实验复现时保留现有输入，不运行prepare覆盖它。

```powershell
python analysis/research_a144_v5_trend.py screen
python analysis/research_a144_v5_trend.py leader-screen
python analysis/research_a144_v5_trend.py stress
python analysis/research_a144_v5_trend.py validate --refresh-minutes
python analysis/research_a144_v5_trend.py leader-validate --refresh-minutes
python -m pytest tests/test_redisqmt_a144_v5.py tests/test_redisqmt_a144_v4.py tests/test_redisqmt_a144_v3.py -q -p no:cacheprovider
```

只读扫描示例（不是下单计划；数据不足时拒绝输出）：

```powershell
python Stragety/RedisQMT/A144/A144_v6_LeadershipRotation.py --asof 20260925 --output analysis/a144_v5_trend_20260926/signals_v6.json
```

验证：29项相关测试通过；两个新增入口帮助命令通过。
下一步有效研究需要补齐更早的真实分钟、历史成分及公司行动；本轮已充分否决这两个具体实现，
不能仅增加杠杆、挑选局部牛市或循环查看后段收益来宣称36%达标。
