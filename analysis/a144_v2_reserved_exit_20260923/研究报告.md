# Alpha144 v2 保留槽位弱势退出研究报告（口径更正版）

## 更正结论

原报告关于 v1、v2 的收益指标作废。研究引擎与实盘策略存在三处口径偏差：旧引擎把3日动量计算成4日动量，在 Alpha144 排名前额外按当日成交额过滤股票池，并在分段回测时错误地从样本起点重新计算10日刷新周期。修正为实盘固定锚点口径后，当前 v2 参数仍优于更正后的 v1，但原有“训练期选参、独立样本外确认”的证据链已经被污染，因此 v2 只能保留为待验证候选，不能据此批准自动实盘。

当前实盘参数为：第12个持有交易日起，收益不高于−4%且收盘低于 MA20 时退出；退出后槽位继续冻结至原20日持有期限届满。

## 参数选择重新审视

修正固定刷新锚点后，仅用训练期重新选择仍会得到“第8日开始、亏损不高于0%、低于 MA20”的候选。其锚定样本外总收益90.16%、年化45.67%，虽高于 v1，但低于当前12日/−4%的105.36%和52.38%，且不是在无污染样本上重新选出，因此不替换当前参数。

当前12日/−4%参数虽然更稳，但最初也是在错误口径下选出，不能把2025年以后数据再次用作无污染的样本外确认。下一轮必须重新冻结候选，并使用滚动样本外、刷新相位和历史成分股验证。

## 原报告错误数字

原报告中的全区间 v2 总收益200.90%、年化26.39%、最大回撤−21.19%、Sharpe 1.341，以及对应的 v1 指标，均来自错误入场口径，不再有效，不得用于版本比较或实盘决策。
