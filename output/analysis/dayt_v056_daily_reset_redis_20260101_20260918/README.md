## 达成率和盈亏的定义

- 单日某方向 T 达成率 = 当天该方向已完成配对的股数 ÷ 当天开盘前实际持股。例如当天有 1,000 股，卖出再买回 1,000 股，则反T达成率为 100%。
- 综合T达成率 = 全部已闭合的反T、正T配对股数 ÷ 各交易日开盘前实际持股数之和。正反方向均完成时可以超过单方向的 100%，这是周转量而不是收益率。
- 已闭合收益扣除了开仓和平仓两侧费用；未闭合腿仅扣实际已成交一侧费用，并按当日收盘价标记，绝不混入“已完成做T收益”。

## 研究解读

- 在该一条样本、该成本假设和截至 20260918 的分钟数据中，期末账户最高的是 **v0561**；这只是样本内排序，不等同于实盘推荐。
- **v056**：已闭合T净收益 1,113.82 元，未闭合腿的日末标记净损益 -2,930.90 元；累计费用 194.08 元，说明结果必须同时看闭合质量、跨日残留与成本，而不能只看触发次数。
- **v0561**：已闭合T净收益 179,856.90 元，未闭合腿的日末标记净损益 -173,534.11 元；累计费用 17,159.21 元，说明结果必须同时看闭合质量、跨日残留与成本，而不能只看触发次数。
- **v0562**：已闭合T净收益 134,109.53 元，未闭合腿的日末标记净损益 -122,951.88 元；累计费用 12,130.34 元，说明结果必须同时看闭合质量、跨日残留与成本，而不能只看触发次数。

- **闭合胜率存在幸存者偏差。** v0561 与 v0562 的正T闭合胜率为 100%，不是“没有亏损风险”：未达到回补/卖回条件的腿被留在当日未闭合列，随后以真实少股或多股的账户状态进入下一日。v0561 的未闭合标记净损益为 -173,534.11 元，正是这种选择性闭合的风险证据。
- **v056 的重启不兼容最明显。** 期末只剩 0 股、全部资产为现金；这不是回测引擎凭空平仓，而是日末反T卖出腿在次日新实例中没有配对上下文，账户仍然保留卖出后的实际股数。它不符合“以底仓做T”的目标。
- **未闭合标记损益不能与期末账户损益相加。** 该数按每个日末独立标记，用于暴露风险腿；同一持仓在后续日可能再次被标记，因此它是风险诊断量而非可加总的账户收益。

## 局限与下一步

1. 数据唯一来自 RedisQMT 桥接，09-18 缺失导致请求窗口未能完整验证；补齐后必须从同一桥接重跑，而不是拼接数据源。
2. 当前是分钟收盘价撮合，未使用盘口队列、成交量参与率、撤单延迟或滑点；实盘收益通常会更低。
3. 每日策略重启会失去未闭合腿的配对上下文。账户没有丢仓，但策略必须具备启动时识别和管理残余腿的持久账本，才能避免将跨日风险误认为新的底仓。
4. 该报告不触发真实委托。QMT实盘下单接口仍应使用成交回报确认；本报告的离线回放只验证策略逻辑。
