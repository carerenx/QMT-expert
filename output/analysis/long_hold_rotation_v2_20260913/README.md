# 长期仓位策略v2：趋势迟滞与低换手优化

## 实施结论

在不修改v1和v55的前提下，新建了`LongHoldRotation_v2_TrendHysteresis.py`。v2使用同一组参数在长电科技、永鼎股份、长飞光纤上回测。三只股票收益和Calmar均高于v1，成交次数下降约78%至89%，但永鼎和长飞最大回撤仍超过30%，且三只均未超过公平全资金持有，因此继续标记为`RESEARCH_ONLY`。

## 新机制

1. 强多头基础仓位由75%提高到100%，普通多头由60%提高到85%，震荡提高到60%，熊市保持30%。
2. 风险增加方向的状态变更需要连续3个交易日确认；转入熊市立即生效。
3. 当前仓位与目标仓位差距不足10个百分点时不交易。
4. 普通调仓后冷却5个交易日；目标仓位不高于45%的风险减仓可以绕过冷却。
5. 账户回撤15%时仓位上限75%，20%时上限45%，25%时降至30%并禁止新增买入。
6. 保留单次调仓不超过账户权益25%、100股整手、现金约束和次日09:40执行。

## 与v55及持有基准

长飞光纤上，v2净收益376,398.90元，高于v55的364,970.49元，多11,428.41元；v2最大回撤33.57%，显著低于v55的50.75%，费用也从6,881.51元降至781.10元。因此在当前长飞一年样本中，v2同时改善了v55的收益、回撤和费用。

v2已经非常接近永鼎的公平全资金持有，只落后9,474.81元；但长飞仍因低仓位和风险退出落后公平持有430,526.10元。不能因为绝对收益或相对v1改善就宣称策略已达标。

## 风险阈值研究

仅研究了三个预先定义的统一风险档位，没有按股票分别优化：

- 原始20%/25%/30%：收益最高，但三只回撤均超过30%。
- 缓冲15%/20%/25%：选为v2当前版本，收益与风险折中最好。
- 防御10%/15%/20%：长电改善，但永鼎和长飞仍超过30%，且两者收益明显下降。

即使把风控阈值提前，日线收盘信号到次日09:40执行仍无法保证最大回撤不穿越30%。这说明30%不能被表述为可保证的硬上限；若必须严格限制，需要盘中组合风控或更低的常态仓位，而这属于下一项新机制。

## 验收判断

优化成功的部分：

- 三只股票收益均高于v1。
- 三只Calmar均提高。
- 成交数和费用大幅下降。
- 长飞同时超过v1和v55。

尚未完成的部分：

- 永鼎、长飞最大回撤仍超过30%。
- 三只股票均未超过公平全资金持有。
- 2025-09-12至2026-09-11已经参与机制选择，不能再作为样本外证据。
- 没有完成未来新增日期或更早独立区间验证。

因此v2保留为研究候选，不解锁实盘。
