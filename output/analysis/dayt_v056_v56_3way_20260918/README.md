## 策略定义

- **v056连续账户**：单runner、无阶梯追加、固定参考线、无最大持有期买回；严格连续账户回放。
- **v056每日重置**：同v056策略参数，但每天独立以10万元现金、1000股底仓和全新策略状态开始。
- **v56连续账户(基线)**：双lane、反T阶梯追加、动态回落/反弹参考；严格连续账户回放。

## 回测口径

- 区间：2025-09-15至2026-09-11。
- 标的：600584.SH、600105.SH、601869.SH；本地1分钟K线。
- 连续账户：每标的初始现金100,000元、底仓1,000股。
- 每日重置：每标的每天100,000元现金、1,000股底仓重新开始。
- 每边费率0.05%、无额外滑点。
- T目标值40,000元；量化单元比例1.0。
- 连续账户超额收益 = 策略期末权益 − 初始现金 − 初始股数×期末收盘价。
- 每日重置最大回撤是所有独立交易日中最差的单日内回撤。
- 期末未闭合腿已按期末价格计入权益，不能视为已实现收益。
