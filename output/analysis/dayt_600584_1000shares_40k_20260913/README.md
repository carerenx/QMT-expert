## 收益差异原因

1. **放大单次金额同时放大了跨日反T尾部亏损。** v53四个亏损周期毛亏损合计8,771元；其中8月4日→5日亏3,155元、8月6日→7日亏2,810元、8月25日→27日亏1,985元。13个盈利周期无法覆盖少数大亏。
2. **v54过滤了部分趋势逆行交易，但没有消除最差两笔。** 它避开v53的8月6日和8月17日亏损周期，也过滤了一批盈利交易；最终超额净收益比v53好766.48元。
3. **期末未买回导致两策略只剩500股。** v53和v54均在9月11日以67.84元卖出500股，期末67.74元时浮盈50元，但仍承担下一交易日跳空及恢复底仓风险。
4. **v40的状态与账户生命周期冲突。** 每日重启丢弃当日未闭合腿，高于1000股的额外库存不会被恢复机制识别，持仓曾达到2200股、期末1700股；股价下跌时库存损失远大于做T价差。
5. **4万元只是目标，不是固定金额。** A股100股整手与现金/可卖仓位约束使实际成交为100—600股，这是按规则降级的结果，不是部分成交错误。

## 可优化点

1. v40必须先实现跨日账本重建和双向库存纠偏：低于1000股恢复底仓，高于1000股识别为待平正T库存，并设置硬上限1500股。
2. 将4万元目标再叠加“单周期最大账户风险”，例如止损损失不得超过初始资产的0.5%；波动扩大时自动缩小股数。
3. v53/v54对跨日反T设置更严格的开仓门槛和隔夜数量上限；日内未买回时，不应让完整4万元风险无条件跨日。
4. 保留v54趋势过滤，并针对8月4日、8月25日两个共同亏损周期研究开盘缺口、MA20斜率及ATR扩张联合禁入条件。
5. 取得完整1分钟数据后复核动态手数、成交时机和最大回撤；不得直接用本区间调出的参数进入模拟盘。
