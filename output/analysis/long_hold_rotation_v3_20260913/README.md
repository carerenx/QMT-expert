# 长期仓位策略v3：分级风险恢复实施与验证

## 实施内容

根据v2全部73笔交易审计，新建v3，未覆盖v2：

- 新增风险状态：`NORMAL`、`DEFENSIVE_75`、`DEFENSIVE_45`、`HALT_30`、`RECOVERY_45`、`RECOVERY_60`、`RECOVERY_75`。
- 回撤15%进入75%防守，20%且趋势弱进入45%，25%且严重弱势进入30%。
- 防守后只有收盘站上MA20、MA20高于MA60、当日企稳、20日趋势效率大于0.20并持续5日，才提高一个恢复档位。
- 强多头降为普通多头时，若没有跌破MA20且趋势效率转负，继续保留强多头状态。
- 保留v2的10个百分点仓位死区、5日调仓冷却、25%单次上限和次日09:40执行。

## 验收判断

v3实现了代码和回测，但不作为v2的全面替代版本：

- 长飞收益、回撤、Calmar和费用均改善，机制命中了长飞的低仓位恢复问题。
- 长电和永鼎收益下降，说明恢复条件仍有标的依赖。
- 三只股票仍全部落后公平全资金持有。
- 三只最大回撤分别为32.27%、35.11%、33.20%，全部超过30%硬目标。
- 当前一年数据已参与机制发现和验证，不是样本外。

因此v3状态为`RESEARCH_ONLY / CANDIDATE_REJECTED_FOR_GENERAL_RELEASE`。保留代码用于下一段独立数据验证，但当前通用默认仍应使用v2研究版本，不解锁实盘。
