# v56：双lane、阶梯追加与动态回落参考消融回测

## 结论

本回测将三个候选简化项分别关闭，其他参数、数据、费用、T+1和连续账户路径均保持一致。
`baseline`为双lane、反T阶梯追加和动态回落/反弹参考均开启的当前v56口径。

结果只能说明固定样本内的影响；未闭合反T腿按期末价格计入权益，但不等同于已完成收益。

样本内判断：

- 关闭双lane的合计超额收益增加88,440.70元，但最差最大回撤由43.99%上升至47.78%，且期末仍有未闭合腿；不能据此认定单lane更优。
- 关闭阶梯追加的合计超额收益增加56,294.78元，但最差最大回撤上升至49.90%，完成周期从61增至413，手续费增加10,376.22元；阶梯明显改变了换手和风险路径，不能直接删除。
- 关闭动态回落/反弹参考的合计超额收益变化仅-0.37元，最差最大回撤不变；在本样本中未显示有意义的收益贡献，是最适合进入行为一致性验证后删除的候选。

## 方案定义

- 基线：显式创建L0/L1，`MAX_OPEN_CYCLES=2`。
- 关闭双lane：只创建L0，`MAX_OPEN_CYCLES=1`。这是同时改变并发周期上限的必要配套；否则单lane仍会保留与实际不符的两个周期容量。
- 关闭阶梯：`LADDER_UP_STEP_PCT=10.0`，即需要卖出后再上涨1000%才会追加，固定样本内等价于关闭反T阶梯；FWD-T本来已禁止开仓，不构成结果差异。
- 关闭动态回落/反弹参考：`REBOUND_ENABLED=False`，实际反T触发线退回quantile基础触发线；不关闭`STRENGTH SHADOW`，因为它在当前shadow模式不参与下单。

## 回测口径

- 标的：600584.SH、600105.SH、601869.SH；本地1分钟K线。
