# v52研究总结与交付边界

## 结论先行

本轮的核心收获不是找到一个“更灵敏必然更赚钱”的参数，而是把**每日重新给资金的比较实验**与**真实保留未平风险的连续账户实验**分开。

v52的固定比较毛收益改善，不能证明其隔夜机制值得上线。连续账户仍可能在卖出后长期未买回，错过底仓上涨；即使完成很多盈利小周期，未完成风险和少数亏损周期仍会抵消收益。最终金额、消融表与哈希以同目录的`DayT_v52_comparison_report.md`为准。

本轮交付独立研究策略，不启用实盘，不替换v51，不改动旧账户检查点，不承诺收益提高。

## 新机制如何工作

文件：`Stragety/MiniQMT_Stragety/DayT/DayT_v52_DirectionalOvernight.py`。

完整保留v51执行代码在新文件内，不导入同级旧策略；共享的纯计算模块为`core/directional_overnight.py`。原执行状态机与新增周期约束在同文件分层，目的在于保留成交确认、退出、日志和保存重试路径，而不是重新发明下单接口。

### 正向准入

用完整分钟计算：

```text
z1 = clip((现价/日内均价 - 1)/(本轮ATR×0.10), -1, 1)
z2 = clip((现价/5分钟前价格 - 1)/(本轮ATR×0.10), -1, 1)
z3 = clip((日内均价/5分钟前均价 - 1)/(本轮ATR×0.10), -1, 1)
瞬时强度 = (z1+z2+z3)/3
平滑强度 = 最近3个完整分钟瞬时强度平均
```

积累至少15个连续有效分钟，并连续3个完整分钟达到准入阈值，才允许新增主正T或MOM正向周期。缺少价格、均价、ATR、发生分钟间断或午休后，重新观察。阈值只研究0、0.20、0.40，默认研究值0.20。

它不是牛熊预测标签：负强度不等于“未来必跌”，正强度也不等于“买入必赚”。它仅给原有正向入场条件加一项过滤，退出不受这项过滤限制。报价时间新鲜度仍按原约定仅告警，不把报价年龄告警另作停单开关。

### 周期隔离与限额

- 每只股票最多两条独立周期通道；每条通道只能拥有一个主策略或MOM周期。
- 阶梯属于其原周期，仍消耗绝对数量额度，不另造一个周期绕开上限。
- 未完成数量按绝对值相加，正反方向不相互抵消。额度按原始底仓50%计算，向交易单位取整。
- 200股底仓只能容纳100股未平T，因此本次历史样本通常只能运行一个未完成周期；“两周期”并不意味着所有账户都能开满两个。
- 周期独立记录开仓日期/时间、方向、均价、数量、退出目标、订单、费用和收益。新周期不能重设另一个周期的退出价。
- 同股执行串行，先处理已有周期，按开仓先后处理，再考虑新增周期。

反向周期预留：

```text
预留 = 剩余数量 × max(开仓成交均价, 当前价) × (1+开仓ATR)
     + 一份研究费用缓冲
```

这不是成本保护，也不是强制止损。它是避免把卖出后准备买回的钱用去开另一个占资周期。预留不足时拒绝新增占资交易，原退出继续管理；一个周期的退出不能拿走另一个周期的预留。

### 换日与恢复

未平周期跨日保留原目标、开仓ATR和成交归属；只刷新每日次数、观察缓存和券商可卖数量。年龄依据已验证交易日累计，满3个交易日告警，不新增到期强制卖回或买回。

v52使用独立检查点。已核对一致且无未平腿的旧账本可以只读导入，保留当日已用次数。旧账本只有订单集合而缺少唯一订单到未平周期的对应关系时，不推测归属，拒绝导入并保留原文件。

已经确认、已经入账的部分成交可以按周期剩余数量恢复；崩溃发生于未知委托结果期间则保留中断标记并要求核对，不绕过原安全保护。这与“任何中断都能全自动继续”不同。

已知停牌/波动中断状态暂停该股；未知状态不是正常交易的证明。仓位与原始底仓加T净变化对不上、日线原始收盘与报价前收盘不一致等情形也需要核对，不能自动改旧目标来消除亏损。[Python API, p.171]

## 保持不动的参数

首轮系数缩放0.60、后续0.80、原基础阈值与手数计算、盘中参考价shadow默认值保持不变。没有同时搜索卖点、手数、牛熊标签和方向阈值。

关闭正向仅作为研究对照，实际重新跑共享资金路径，不从旧方向收益表简单做加减。

## 如何理解验收失败

1. 旧版因跨日未平账本不能连续运行时，不能通过修改旧策略把它包装成合格基线。
2. 所有候选均不满足选择条件，就保留研究版和失败结论；不能因为必须交付版本号而强行挑选“最优上线版”。
3. 每日重置实验中的改善，不会自动延伸到连续账户。隔夜需要单独计入未平估值、持有时长、资金占用和相对持有损益。
4. 5bp及最低5元是研究假设，真实费用未确认，不能宣布实盘净收益验收通过。
5. 没有累计5个交易日影子观察，更没有20个新增交易日和30个新增完整周期。本轮已经看过的99天不能变成真正样本外。
