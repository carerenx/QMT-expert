# CaptureT 四版本实测：反T / 正T / 两个都做 / 加日线风控

## 一句话

|---|---|---:|---:|---:|

**v4 是唯一跑赢 v1 的版本：88,331.57 元，是 v1 的 7.0 倍。** 它的增量不来自做T，而来自**一次离场**：2026-07-03 在 475.08 清掉底仓、08-11 在 335.92 买回，躲开了 601869 在 6/24–8/3 那波 **−54.8%** 的回撤。

**换句话说：只换「允许哪个方向做T」，结果只在 +368 ~ +12,702 之间挪；加一层日线风控，量级直接变成 +88,332。风控比做T 重要一个数量级。**

代价见后面「v4 的两条必须一起读的证据」——它在 Q1 是**亏**的，全部收益来自 Q3 那一次；而且 8 月之后它每天都在翻仓（34 次风控事件里 29 次在 8 月后）。


## 口径

- 标的 **601869.SH**，1 分钟线全部取自 **RedisQMT 桥接**（`get_market_data_ex`）。
- 区间 **2026-01-01 ~ 2026-09-18**（174 个交易日）。
- 初始仓位 ≈ 100,000.00 元 → 实得 **800 股**（8 手）+ 现金 100,000.00 元。
- **每个交易日新建策略实例**；现金、持仓、手续费跨日连续；日末未平腿不强平、不丢弃。
- **每笔新 T 腿 = 一半仓位 = 400 股**；正T 额外受「现金能买多少手」约束。
- 成交撮合为触发当根 1 分钟收盘价，单边 0.05%，滑点 0。
- **手续费在当日结算时实际扣除**（回放引擎撮合时本身不收，本脚本补齐），扣费后的现金参与次日的正T 买入能力。以下所有「期末资产 / 相对一直持有」都是**扣费后的净数**；`手续费` 一列只是把这笔钱单独列出来，**不要重复相减**。

## 正T 是怎么落地的（T+1 约束下）

A股 T+1：当天买的不能当天卖。所以正T 必须拆成两步，且**卖出必须来自底仓**：

```
起始：底仓 800 股（全部可卖）

  价格 <= VWAP - 3σ   ① 用现金买入 N 股      → 持仓 800+N，新买的 N 股当日不可卖
  价格 >= VWAP + 3σ   ② 卖出【底仓】N 股      → 持仓回到 800 ✓   P&L = N×(卖价−买价)
  14:57 仍未触发②     ③ 同样卖底仓 N 股       → 持仓回到 800（保证收盘净持仓 = 底仓）
```

净持仓全程不变——这正是「做T」的定义。反T 卖的是底仓、买回来，正T 买的是现金、卖底仓回去，两条腿在账面上是对称的。

唯一的实质差别：**反T 不占现金，正T 占**。所以正T 的手数会随股价上涨被现金压缩——见下面「正T 的实际规模」。

**一个必须说明的口径差异**：账户级数字（`期末资产(净)`、`相对一直持有(净)`）直接来自回放引擎的现金与持仓，精确；但 `反T已实现 / 正T已实现` 是按**当日**流水做 FIFO 配对算的。CaptureT 每天 14:57 强制归位，两条腿当天闭合，两者的恒等式 `毛收益 − 手续费 = 相对一直持有` 逐策略成立（v1: 15,660.00 − 2,958.32 = 12,701.68 ✓；v2: 12,838.00 − 3,256.44 = 9,581.56 ✓）。v0561 / v0562 **不成立**——它们的腿经常跨日未平（未闭合日 102 / 76 天），当日配对会把跨日的未实现盈亏丢掉，所以这两行的分腿数字只是近似，**请只信任它们的账户级数字**。

## v1 → v2 逐日拆解：钱到底漏在哪

v2 的 6 笔正T 按「v1 当天本来会做什么」分成两类。这是精确拆解，不是估计：

### ① 替代日 —— v1 本来会做反T，v2 改做了正T（2 天）

| 日期 | v1 反T | v2 正T | 差 |
|---|---:|---:|---:|
| 20260114 | 892.00 | 1,408.00 | **516.00** |
| 20260506 | 3,576.00 | 4,827.00 | **1,251.00** |
| **小计** | | | **1,767.00** |

**这一类正T 做得比反T 还好**，合计多赚 1,767.00 元。所以「正T 这条腿本身不行」是错的。

### ② 新增日 —— v1 当天整天没出手，v2 开了新仓（4 天）

| 日期 | 正T 平仓时间 | v2 正T |
|---|---|---:|
| 20260123 | 14:57:00 | -276.00 |
| 20260722 | 14:57:00 | -2,235.00 |
| 20260813 | 14:57:00 | -876.00 |
| 20260826 | 14:57:00 | -1,202.00 |
| **小计** | | **-4,589.00** |

**全部漏损都在这一桶：-4,589.00 元。**这 4 天 v1 一笔不做（价格**先**跌破下带，但当天始终没有再冲上带），v2 却因为「跌破下带 = 便宜」而买入，然后一路持有到尾盘强平。
4/4 笔都是 **14:57 强平**收场，**没有一笔被上带正常止盈**——因为那几天价格压根没回去。换句话说，**下带触发的是一个「买入」动作，但没有任何证据表明它是一个「会上涨」的信号。**

相加：1,767.00 + -4,589.00 = **-2,822.00**，与**毛**差额一致。

从毛差额到净差额：v2 的手续费比 v1 多 298.12 元（正T 多交易 6 次），所以净差额是 -3,120.12 元。**下面所有结论用净数。**


## 正T 的实际规模：现金把它越削越小

设计上每条新腿 = 底仓的一半 = **400 股**。反T 卖的是底仓，永远拿得到 400 股；正T 要先掏现金买，所以实际手数 = min(400, 现金 ÷ 价格 向下取整到整手)。601869 从年初的 ~110 元涨到期末的 455 元，现金只有 100,000.00 元不变，于是同一条规则买到的股数一路缩水：

| 日期 | 开仓价 | 可买手数上限 | 实际股数 | 名义 400 股的现金需求 |
|---|---:|---:|---:|---:|
| 20260114 | 105.91 | 900 | **400** | 42,364.00 |
| 20260123 | 113.26 | 800 | **400** | 45,304.00 |
| 20260506 | 353.90 | 200 | **300** | 141,560.00 |
| 20260722 | 373.50 | 200 | **300** | 149,400.00 |
| 20260813 | 340.41 | 200 | **300** | 136,164.00 |
| 20260826 | 394.11 | 200 | **200** | 157,644.00 |

从 400 股一路降到 200 股。**这不是参数没调好，是账户结构的硬约束**：只要底仓和现金都是 10 万元级别，股价涨到 300 元以上时正T 就只能做半条腿。在这一点上，反T 相对正T 有结构性优势。


## 结论：这条规则的价值几乎全部在反T 那一侧

把「允许哪个方向开仓」当成唯一变量，其余全部冻结，得到的是一个干净的排序：

```
只做反T   +12,701.68      ← 有效
两个都做   +9,581.56      ← 被正T 拖累
只做正T      +367.52      ← 等于零
```

1. **只做正T 基本不产生收益。** 6 笔交易、毛收益 782.00 元，扣掉 414.48 元手续费之后只剩 367.52 元。账户是 19 万元级别、区间 174 个交易日，**367.52 元相当于 0.19% 的总收益、+0.0011%/天**——在噪声里，等于没做。

2. **正T 的每一笔在方向上都不是「+1 块钱」的差异，而是方差问题。** 6 笔里最大的一笔 4,827.00 元（0506）、最差的一笔 -2,235.00 元（0722），6 笔合计才 +782。**换句话说：正T 的收益完全由 1–2 笔决定，其余是噪声。**

3. **正T 的手数被现金一路压缩。** 反T 卖的是底仓、不受现金约束，永远拿得到 400 股；正T 必须先掏现金买，而账户里始终只有 100,000.00 元。601869 从年初 ~110 元涨到年末 ~455 元，同样的 400 股从 42,364.00 元涨到 157,644.00 元。v3 是纯正T 账户（没有反T 利润补充现金），后期只能买 200 股——**腿越做越小，而这恰恰发生在波动最大的时段。**

4. **v2 的漏损不是「正T 亏了」，是「正T 顶掉了反T」。** 正T 那 6 笔本身是正的（+1,646.00 元），其中替代掉反T 的 2 笔还多赚 1,767.00 元；但从 v1 到 v2，反T 少了 2 笔、少赚 4,468.00 元。**一天只允许一趟，先触下带就做正T，当天再冲上带就做不了反T 了。**

5. **样本量让上述任何一条都不能当成定论。** 正T 只有 6 笔、反T 只有 23 笔，两条腿的 t 值分别是 0.27 和 0.79，**都不显著**。上面说的是「没有任何证据支持正T」，不是「已经证明正T 无效」。

### 这对 v1 的结论意味着什么

v1 报告的结论是「+12,702 不能复现，是分布里有利的尾部」。三件套给这个结论加了一条更强的证据：**换一个方向，结果从 +12,702 掉到 +368**——同一个规则、同一份数据、同一段行情，**只把一个布尔量翻过来，35 倍就没了**。一个真正稳健的效应不会这样。

同时它也回答了 v1 文档里留下的那个问题（「只有反T 是不是一个缺陷」）：**不是缺陷。** 在这条规则下，

> **上带（VWAP+3σ）卖出 > 什么都不做 > 下带（VWAP−3σ）买入。**

**下带凭什么是买入信号？** 本实测没有给出任何支持。
