## 策略说明

- **策略版本**：v056_nomom（DayT_v056_nomom_SimplifiedReversal.py）
- **正T冻结**：`LONG_RESEARCH_DISABLED=True`，仅运行反T（先卖后买）。
- **正T开启**：`LONG_RESEARCH_DISABLED=False`，反T+正T同时运行。
- 正T（Forward-T）= 先买后卖：利用现金买入额外股份，高位卖出获利。
- 反T（Reverse-T）= 先卖后买：卖出底仓股份，低位买回获利。

## 回测口径

- 区间：2026-07-28至2026-09-11。
- 标的：600584.SH、600105.SH、601869.SH；本地1分钟K线。

- 每边费率0.05%、无额外滑点。
- T目标值40,000元。
- 日末未闭合腿不会带入次日。
