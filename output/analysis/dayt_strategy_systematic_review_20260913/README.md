# 做T策略系列系统性梳理与下一代优化建议

## 执行摘要

本系列从 v39 的日内反T框架，逐步加入连续账户、底仓恢复、方向判断、跨日周期管理、趋势过滤和日终回补。工程安全性持续改善，但收益问题仍未根治：策略擅长赚取多数小幅均值回归，却会在少数强趋势日发生较大的反T回补亏损；同时，频繁交易产生的费用会侵蚀原本有限的毛利。

以 BigQMT Redis RPC 取得的1分钟K线为当前最可信口径。相同的10万元现金、1000股底仓、约4万元单次目标和双边各0.05%费用下，v55在永鼎股份取得+443.19元超额净收益，但长电科技仍为-1,383.37元。长电 v55 的18个周期有11胜7负，胜率61.1%，仍然输给持有；这直接证明“胜率较高”不是目标，关键是盈亏比和持有机会成本。[^1]

下一版不应继续围绕单一ATR倍数或固定时间做小幅调参。建议以 v55 的安全框架为基础，新建 v56，核心改为：

1. 费用后预期收益门控；
2. “过度延伸+拐点确认”双条件开仓；
3. 核心底仓与T仓分离、按风险动态定仓；
4. 趋势日切换为正T/不交易，禁止机械反T；
5. 以相对持有超额收益而非账户绝对收益作为优化目标；
6. 使用滚动样本外和扰动测试决定是否发布。

## 一、策略谱系

| 版本 | 核心变化 | 解决的问题 | 新增代价或遗留风险 |
|---|---|---|---|
| v39_nomom | 反T主策略，先卖底仓、回落后买回 | 建立基础日内高抛低吸 | 每日重启会丢失未平仓状态；只有卖出能力，没有可靠底仓恢复 |
| v40 BaseRecovery | 每日重启账户连续；复用正T信号恢复底仓 | 避免直接用卖一价无条件补仓 | 策略状态每天清空，与连续持仓状态不完全一致；恢复可能延迟 |
| v51/v52 | 多周期、方向、强弱、正反T框架及执行保护 | 丰富信号和连续状态管理 | 状态机庞大，机制耦合；参数多，归因困难 |
| v53 CycleRiskExit | 未平仓周期增加不利波动和最大持有期退出 | 防止无限跨日持有反T腿 | 强制退出可能在趋势顶部附近高价买回；仍可能永久减仓 |
| v54 TrendGuard | 对反T增加趋势过滤 | 减少上涨趋势中的错误卖出 | 过滤基于低频趋势，无法识别日内加速；长电1分钟结果反而弱于v53 |
| v55 NoOvernightMomentumGuard | 5日动量门控、14:50恢复底仓、1%/0.1ATR不利退出 | 消除跨日反T腿，限制尾部损失 | 固定3%和14:50具有周期依赖；1分钟下长电仍输基准 |

这条演化路径证明了两点。第一，连续账户、T+1、状态恢复和未平仓腿必须是不可退让的安全底座。第二，新增保护并不必然增加收益；风险规则如果只决定“何时认亏”，而没有改善“是否值得开仓”，往往只是改变亏损发生的时间。

v55相对前代明显减少了尾部损失。永鼎 v53 最差周期约-1,570.53、-1,462.21和-1,384.04元；v55最差三个周期缩小到约-354.34、-318.46和-229.01元。长电 v53 出现约-3,202.88和-3,022.29元的大亏；v55最差周期仍约-1,621.62元，说明长电的趋势风险尚未被充分识别。[^1]

### 五分钟与一分钟冲突

5分钟回测中，v55在长电和永鼎的超额分别为+564.72和+312.04元；切换为QMT原始1分钟后，结果变为-1,383.37和+443.19元。长电完整周期从12个增至18个，费用从418.28增至642.37元。[^2]

这不是简单的数据误差，而是策略具有明显的周期敏感性：

- 触发逻辑对分钟内高低点和收盘顺序敏感；
- 更细周期产生更多开仓机会，但新增机会的边际质量较差；
- 固定阈值没有把预期毛利与交易成本绑定；
- 同一日可能重复进入相同的市场状态，形成相关性很高的“伪多样化交易”。

因此，今后只能把1分钟作为主回测口径，5分钟用于稳定性对照，不能反过来用5分钟最优参数指导1分钟实盘。

## 三、根因诊断

### 1. 优化目标错位

账户赚钱不等于做T有效。上涨期间即便策略产生正收益，也可能因为卖掉底仓后少吃上涨而输给一直持有。正确目标应为：

`超额净收益 = 策略最终资产 - 同现金与同初始底仓的持有最终资产`

开仓决策也应估计“卖出底仓的机会成本”，而不只估计回落概率。

### 2. 反T信号只描述价格位置，没有充分描述路径

价格高于参考位只说明“涨得高”，不等于“即将回落”。真正有用的反T信号需要同时满足：

- 延伸：相对VWAP、开盘、前收或ATR已经足够高；
- 衰竭：上行动量减弱、创新高失败或冲高回落；
- 流动性：预期回落空间覆盖费用与滑点；
- 状态：市场不是单边趋势或涨停附近。

当前趋势过滤主要依赖日线，日内加速识别不足，因此长电仍会在强趋势途中卖出。

### 3. 固定4万元不是风险等额

同样4万元名义金额，在不同股价、ATR和趋势强度下风险完全不同。长电和永鼎的波动结构不同，却使用同样目标金额，会让单笔潜在损失不一致。仓位应由允许亏损反推，而不是先定交易金额。

### 4. 费用门槛没有进入开仓条件

按双边各0.05%计算，最低往返成本约为成交额的0.10%，尚未计滑点和最低佣金。若正常回落目标仅略高于成本，胜率即使不错也没有足够安全垫。1分钟下新增的交易次数提高了费用，却没有同比提高毛收益。

### 5. 多机制耦合导致归因困难

当前策略同时包含分位数、日内强弱、反弹确认、方向、阶梯、周期风险、涨停保护、正反T和大量执行状态。一项交易可能被多个规则共同影响。版本通过整文件复制演进，也使行为差异难以审计。收益优化需要先建立稳定的“信号—订单—成交—周期—超额归因”数据层。

## 四、建议的新一代 v56 机制

按照仓库规则，这是新增机制，应新建完整策略文件，不修改 v55。

### 优先级A：费用后边际门控

每次开仓前计算：

`净边际 = 预期回落幅度 - 往返费率 - 保守滑点 - 卖出机会成本`

只有净边际大于安全阈值才允许交易。初始研究可不用复杂机器学习，而用滚动历史分箱：按趋势状态、延伸幅度、时段和波动率将历史信号分组，只使用此前交易日估计各组的中位回落和失败分位数。这样既可解释，又避免把未来数据泄漏到当天。

建议验收：被过滤交易的合计净收益应为负；保留交易在相邻阈值下均为正；门控后每个分箱至少有足够样本，否则默认不交易。

### 优先级A：延伸与拐点双确认

反T卖出从“达到高位”改为两阶段：

1. `ARMED`：价格相对日内VWAP或开盘达到动态延伸阈值；
2. `CONFIRMED`：随后出现创新高失败、从局部峰值回撤，且短周期斜率转负；
3. 只有确认后卖出。

动态延伸阈值建议取：

`max(费用安全垫, 日内实现波动分位数, 个股近期同时间段噪声分位数)`

它比固定ATR倍数更适合1分钟数据，因为早盘与午后噪声水平不同。代价是可能少赚最顶部的一段，但能显著减少趋势途中逆势卖出。

### 优先级A：核心仓与T仓隔离

把1000股拆成不可主动降低的核心仓和可循环T仓，例如研究初值：

- 核心仓600股：除账户级风险外不做反T；
- T仓400股：用于反T或正T；
- 当趋势置信度高时，反T仓降至0—200股；震荡且延伸确认充分时才升至400股。

这能直接限制相对持有的机会成本。仓位公式应以风险预算为主：

`股数 = min(T仓上限, 单周期允许亏损 / 止损距离, 现金或可卖数量约束)`

最终按100股向下取整。单周期允许亏损可先研究为账户净值的0.15%—0.30%，而不是固定4万元。

### 优先级B：市场状态路由，而非单一趋势开关

将交易日分成三类，并为每类配置不同动作：

| 状态 | 识别特征 | 动作 |
|---|---|---|
| 单边上涨 | 价格持续在VWAP上方、回撤浅、高点抬升、行业/指数同步 | 禁止反T；允许正T或持有 |
| 震荡 | VWAP反复穿越、方向效率低、上下影均衡 | 启用标准反T和正T |
| 单边下跌 | 价格持续在VWAP下方、低点下移 | 禁止新增正T；反T仅在反弹衰竭后小仓执行 |

方向效率可用“净位移/累计绝对分钟变化”表达，比单纯3日或5日收益率更贴近当日可交易结构。分类必须只使用当前时点之前的数据。

### 优先级B：损失后的状态冷却

同一市场状态内连续交易不是独立机会。建议：

- 不利退出后至少冷却30—60分钟；
- 当天发生一次超过风险预算的亏损后，反T仓位减半；
- 当天累计净亏损达到上限后停止新开仓，但仍允许恢复底仓；
- 两次同方向失败后，只有市场状态重新分类才可再次开仓。

这比简单限制每日次数更有意义，因为它阻止的是同一错误假设的重复下注。

### 优先级B：退出机制按原因拆分

正常盈利回补、动量反转止损、日终恢复底仓是三种不同决策，不应共享一个固定阈值：

- 正常回补：达到费用后目标，并出现下跌衰竭或反弹确认；
- 趋势止损：市场状态转为单边上涨时立即缩短等待，不必等固定1%；
- 日终回补：保留14:50—14:55安全窗口，但应在更早时停止新开反T；
- 对日终回补单独统计净收益，判断它是在降低尾部风险还是长期制造小亏。

### 优先级C：正T作为状态互补，而非全天并行

当前研究主要依赖反T。在强势股样本中，单纯反T天然承担错失上涨的机会成本。创新方向是使用同一个状态路由：强上涨状态关闭反T，只在回撤后出现恢复信号时使用正T；震荡状态允许双向但共享风险预算；弱势状态限制正T。

正T必须显式满足A股T+1库存约束：当天买入的新增股票不能当天卖出，卖出动作实际使用昨日可用底仓；策略账本必须区分交易配对与券商可用股份，不能把经济意义上的正T配对等同于当天新买股份可卖。相关订单和持仓查询应继续通过已核验的QMT接口实现。[Python API, p.101]

## 五、研究与验收设计

### 冻结主口径

- 数据：BigQMT Redis RPC原始1分钟K线；不复权用于成交模拟，前复权日线可用于信号，但两者必须显式区分；
- 账户：10万元现金+1000股；连续账户；
- 成交：下一根可成交事件，不允许同根K线同时看高低价并成交；
- 成本：至少测试0.05%、0.08%、0.10%三档单边综合摩擦；
- 基准：同初始现金和底仓的一直持有；
- 主指标：超额净收益；约束指标：最大回撤、最差周期、底仓缺口时间、费用占毛利、成交拒绝与未平仓腿。

### 采用消融实验

每次只增加一个机制，顺序建议：

1. v55 + 延伸/拐点双确认；
2. 再加费用后边际门控；
3. 再加动态风险仓位；
4. 再加状态路由及正T互补；
5. 最后研究执行价格和委托方式。

每一步同时报告“新增过滤掉哪些交易、这些交易原本合计盈亏多少”，避免只看最终净值而无法知道提升来自哪里。

### 滚动样本外

当前只有30个交易日，不能再把同一区间同时用于选参数和宣称有效。建议扩展QMT历史数据后采用：

- 训练60个交易日：只估计分位数或状态统计；
- 验证20个交易日：选择机制，不选择精确最优点；
- 测试20个交易日：完全冻结；
- 每20日向前滚动一次，汇总所有真正样本外交易。

发布条件建议同时满足：两个标的及合计超额为正；多数滚动窗口为正；成本提高后仍为正；最差周期受控；参数上下扰动20%不改变结论；最终持仓恢复到目标且无未平仓腿。

## 六、优先实施路线

| 顺序 | 工作项 | 预期收益作用 | 实施难度 | 判断标准 |
|---:|---|---|---|---|
| 1 | 建立逐信号反事实归因表 | 找出真正损失来源 | 中 | 每个被触发/过滤信号都有未来最大有利/不利变动及费用后收益 |
| 2 | 延伸+拐点双确认 | 减少趋势途中卖出 | 中 | 长电最差周期显著缩小且超额改善 |
| 3 | 动态风险定仓、核心仓隔离 | 限制机会成本与尾部 | 中 | 最差周期不超过预设账户风险预算 |
| 4 | 费用后边际门控 | 删除低质量高换手交易 | 中 | 费用/毛利下降，保留交易期望值提高 |
| 5 | 状态路由正T/反T | 在上涨环境减少基准落后 | 高 | 强趋势窗口的超额不再系统性为负 |
| 6 | 滚动样本外及成本压力测试 | 排除样本内幻觉 | 高 | 冻结测试集和相邻参数均通过 |

不建议优先做的事情：继续搜索14:47或14:52之类精确时间；围绕3%动量门槛做小数点优化；只提高交易次数；只看胜率；用5分钟优于基准的结果覆盖1分钟失败。这些做法更可能放大过拟合，而不是产生可迁移的收益来源。

## 七、最终判断

v55应作为下一代的安全基线，而不是收益完成版。它已经解决了跨日丢腿和大部分极端回补风险，并在永鼎1分钟数据上小幅超过持有；但长电仍然失败，证明固定动量门控无法跨标的稳定工作。

最有希望的创新不是更复杂的指标堆叠，而是将每次做T变成一个明确的经济决策：只有当“状态允许、价格已延伸、拐点已确认、费用后边际为正、风险预算容许”五项同时成立时才交易。减少低质量交易、限制底仓机会成本，再用正T补足强趋势环境，才可能使超额收益具有稳定性。
