# v51统一盘中强度：研究、实施与验证报告

日期：2026-09-10。

### 后续参数调整：首轮quantile系数缩放

按用户追加要求，v51开头新增 `QUANTILE_UNITS_SCALE=0.80`。首轮历史quantile系数乘此参数后用于真实执行阈值，公式日志打印raw、scale及结果；**即使shadow模式，此项也影响首轮执行参考**，不同于只观察的分钟强度候选。设置1.0恢复未缩放值，必须为有限正数。

保存原始未缩放系数，同日恢复会按当前参数重算，但不会重复乘0.8。`CLOSE_FILL_ATR`后续轮次不受此项影响，已有交易腿买回目标不变。示例0.698×0.8=0.5584；按显示的437.32元、ATR6.54%计算约453.29元，真实日志可能因内部精度略有差异。追加测试后149项通过。下文历史统计是追加缩放前的研究基线，不能视为0.8参数回测结果。

## 研究依据：不能把昨日大涨等同于今日休息

故障背景：长飞当天开盘437.32元，原阈值457.27元。v50把价格重新高于开盘价直接当作转强，却要求价格低于开盘价/均价中较低者至少0.08倍ATR，且持续3分钟，才启用弱势参考。因此436～438元附近整理容易被遗漏。

原阈值来自约71.4%的历史上行分位与约6.54%的ATR。昨日上涨可能影响两者，但不能据此认定次日应该反转。Gao等基于中国个股高频数据发现日内动量，并发现正面信息冲击后的可预测性减弱；这并不等于次日必休息，也不直接支持某个折减比例。[作者论文页面](https://mpra.ub.uni-muenchen.de/96784/)

本地301根长飞日线，2025-04-17至2026-07-14：昨日涨幅为正且达到此前最多80期涨幅的75%分位，归为“昨日强涨”。探索结果：

| 分类 | 次日样本数 | 次日开盘至最高涨幅中位数 |
| --- | ---: | ---: |
| 昨日强涨 | 78 | 4.023% |
| 其他 | 200 | 3.041% |

这是单股旧样本描述，不是因果结论，也未控制市场阶段或波动率。本实现不增加“昨日强涨就降价”的交易条件，昨日表现仅作为研究背景。

## 已实现公式与参数

首轮基准B为有效开盘价；后续轮B为原机制确认的平仓均价。原阈值T0与对应ATR不改变。Ul取最近最多80根完整日线中，上行ATR单位的35%分位，并截断到不高于原系数。

```text
开盘分量 = clip((P/O - 1)/(ATR × 0.25), 0, 1)
均价分量 = clip((P/VWAP - 1)/(ATR × 0.10), 0, 1)
动量分量 = clip((P/P_10分钟前 - 1)/(ATR × 0.10), 0, 1)
瞬时强度 = max(开盘分量, 均价分量, 动量分量)
S = 最近3个完整分钟的瞬时强度平均

U0 = max(0, (T0/B - 1)/ATR)
U = Ul + S × (U0 - Ul)
线性价 = B × (1 + ATR × U)
反弹要求 = clip(ATR × 0.25, 0.8%, 2.0%)
候选 = min(T0, ceil-cent(max(线性价,
                           VWAP × (1 + ATR × 0.05),
                           最近10分钟低点 × (1 + 反弹要求))))
```

强度达到0.8时视为明显转强：在未触价的情况下恢复原参考；已按降低参考启动但未成交的监控则取消、退回预占次数。已按原阈值启动的监控保持冻结，不误退次数。

参数集中在v51开头：`STRENGTH_HISTORY_DAYS=80`、`STRENGTH_LOWER_QUANTILE=0.35`、`STRENGTH_LOOKBACK_MIN=10`、`STRENGTH_SMOOTH_MIN=3`、`STRENGTH_WARMUP_MIN=15`，以及各ATR尺度、反弹边界、强度阈值与日志间隔。非法分母、窗口、分位或反弹范围在引擎构造时拒绝，不等待盘中除零。

按计划阶段保存的同轮历史，在S=0、不考虑额外均价和反弹保护时，长电第二轮约69.07元，长飞首轮约446.29元。这是公式示例，不是当前时刻价格预测。

## 分钟观察、触发顺序和恢复

- 每个分钟桶结束才使用其最后观测价、均价和最低观测价；只计算已关闭分钟。首个不完整分钟不计入，累计15个连续有效分钟才启用新参考。
- 当前实现保守要求分钟桶首个观测在该分钟开始5秒内；中途不完整桶、跨分钟缺口或采样间隔超过90秒会重新预热。日内均价为既有行情接口提供的累计成交均价，不伪造高低点之间路径。
- 无效价格、缺行情、缺开盘价/均价/ATR、历史样本不足时回退；午休与非交易时段主动清窗口。90秒仅是本进程采样连续性检查，**不是交易所时间戳新鲜度保证**。
- 在更新参考前先检查当前价是否触及上一有效参考；触及时保留它，不随着上涨追高。若仅因新候选下降到现价以下，不立即启动，保留上一参考并记录 `BELOW_MARKET_HOLD`。
- active模式达价后冻结；继续原回撤确认。原阈值监控和降低后监控均冻结，但仅后者在明显转强时取消并退回一次预占次数。
- 已有主正反T、MOM腿、阶梯腿不受新参考调整；买回、卖回、手数、预留资金、成交核算、异常保存重试不变。
- active下HB、反T入口与MOM让权读同一个有效参考；shadow下三者仍读同一个v50参考，新价独立记录。
- 沿用v49/v50兼容检查点与账户核对。新引擎缓存不持久化，重启重新观察；降低参考后的未成交监控在active重启时取消预占，不丢已成交腿或已完成次数。
