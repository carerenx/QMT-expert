# v54 TrendGuard 优化与回测报告

## 结论

可以在本次历史之外更克制地优化v53，而不是针对四笔亏损交易逐笔打补丁。新建策略 `DayT_v54_nomom_TrendGuard.py` 后，2026-08-03至2026-09-10严格连续账户回测的超额净收益由v53的-703.53元提高到v54的+5,108.52元，历史结果已超过同期一直持有。

v54仍是研究候选，未授权实盘。当前规则是在已观察数据上提出，必须继续滚动样本外验证。

## 优化机制

v53的28个周期毛收益约为+329元，但研究费用为1,032.53元，并发生4次较大的逆向风险退出。500日日线信号验证也显示，长飞光纤处于极强牛市，多数传统卖出或逃顶信号在该环境中无效或表现为反向信号。

v54因此新增一个无需参数搜索的反T趋势闸门：

```text
截至昨日的3个交易日收益率 <= 0：允许新开反T
截至昨日的3个交易日收益率 > 0：禁止新开反T
```

- 只使用已完成日线，不读取当日未来数据。
- 只阻止新的反T周期。
- 正T不受影响。
- 已有周期的正常买回、风险退出和最长持有退出不受影响。
- 历史不足或价格无效时关闭新反T，执行失败关闭原则。
- v53的周期所有权、检查点、部分成交和风险退出机制全部保留。
