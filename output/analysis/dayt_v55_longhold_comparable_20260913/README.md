# v55 与长期仓位策略 v1 同口径一年回测对比

## 回测口径

- 区间：2025-09-12至2026-09-11，共242个交易日。
- 数据：BigQMT Redis RPC，QMT不复权1分钟K线；日线用于指标预热。
- 初始账户：10万元现金＋1000股。
- v55单次目标交易金额：4万元，不足时受现金、持仓及整手约束。
- 费用：单边0.05%，最低5元；严格连续账户，不按日重置现金与持仓。
- 对比对象：`LongHoldRotation_v1_TrendAllocation`此前相同日期、相同初始账户的结果。

QMT返回的首个交易日分钟数据从10:47开始，之后交易日完整；v55首笔成交分别出现在2025-09-25和2025-09-18，因此首日缺失没有直接删除v55成交。两套策略均按此前长期策略所采用的同一起止口径比较，但该数据边界仍作为限制披露。

## 直接比较

### 长电科技

- 长期仓位v1比v55多赚16,706.86元。
- 长期仓位v1最大回撤低4.10个百分点，费用少2,610.86元。
- v55完成136个T周期、286笔成交，费用和错误交易累积抵消了部分底仓上涨收益。
- 原始1000股持有收益为29,620元；v55少赚6,704.91元，长期仓位v1多赚10,001.95元。

### 永鼎股份

- 长期仓位v1比v55多赚119,990.26元。
- v55最大回撤比长期仓位v1低4.20个百分点，但为此牺牲了大量上涨收益。
- v55完成146个T周期、292笔成交，费用2,516.19元。
- 原始1000股持有收益为30,670元；v55少赚4,686.19元，长期仓位v1多赚115,304.07元。

## 结论

在统一为一年、连续账户、Redis QMT 1分钟数据后，长期仓位策略v1的账户收益在两只股票上均高于v55。长电不仅收益更高，最大回撤也更低；永鼎的v55将最大回撤从30.71%降到26.51%，但净收益仅为长期策略的约17.8%。

v55没有在一年样本中创造做T超额：长电相对原始1000股持有为-6,704.91元，永鼎为-4,686.19元。此前约30个交易日中永鼎+443.19元的小幅超额没有延续到一年，说明该结论具有明显样本期依赖。

长期仓位策略仍然不能据此判定合格：它在两只股票上都落后“期初全资金买入并持有”的公平基准，永鼎最大回撤还超过30%硬上限。本次结论仅是“长期仓位v1优于v55”，不是“长期仓位v1已经战胜所有持有基准”。
