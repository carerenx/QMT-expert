## 一、要回答的问题

> 在只有 OHLCV + 成交额的数据条件下，**扣成本后、样本外**，
> 有没有可用的横截面选股因子？如果有，组合起来能否跑赢等权基准？

### 本批测不了什么（先划边界）

数据只有价量。**测不了价值 / 质量 / 盈利因子** —— 而 A 股已发表证据最强的
恰恰是价值（Liu-Stambaugh-Yuan 2019 的 CH-3 里 EP 是最强因子）与质量。

**如果本批价量因子样本外全灭，诚实的下一步是补基本面，不是继续在 OHLCV 里挖。**

### 与仓库既有研究的分工

`analysis/选股器研究结论.md` 已否掉 ER / 年化波动率 / 价格位置 / 方差比 VR /
日收益一阶自相关 ac1。但那批研究问的是「**什么样的股票适合趋势跟踪**」，
是**单标的择时**问题。本批问的是「**同一时点上哪只股票的未来收益更高**」，
是**横截面定价**问题。两个问题不同，**本批不重复测那五个特征**。

| 项 | 值 |
|---|---|
| 来源 | redisQMT 桥接（唯一可用源） |
| 股票池 | akshare 当前在市 ∪ akshare 退市名单 = 5,554 只 |

### 数据源的已知缺口（诚实声明）

| 缺口 | 影响 |
|---|---|
| 历史 `isST` 拿不到，用「过去 60 日 max\|收益\| ≤ 5.5%」推导 | ST 过滤与 ±5% 板判定可能有误 |

| 股息税未计 | 乐观偏差约 0.3%/年 |

**F9 的剔除是数据源缺口导致的，不是结果驱动的。** 这句话写在这里是为了
防止日后有人把这当作「试过但无效」。

## 三、预注册因子与方向

方向在看结果之前写死。**事后改符号 = 该因子作废。**

| # | 因子 | 方向 | 公式（全部基于前复权序列） |
|---|---|---|---|
| F1 | 12-1 动量 | **+** | `adj_close[t-20]/adj_close[t-250] - 1` |
| F2 | 1 月短期反转 | **−** | `-(adj_close[t]/adj_close[t-20] - 1)` |
| F3 | 1 周反转 | **−** | `-(adj_close[t]/adj_close[t-5] - 1)` |
| F4 | 截面 TSMOM | **+** | `sign(adj_close[t]/adj_close[t-120] - 1)` |
| F5 | 52 周高点接近度 | **+** | `adj_close / max(adj_high, 250 日)` |
| F6 | MAX（彩票偏好） | **−** | `-mean(过去 20 日最大的 5 个日收益)` |
| F7 | 特质波动率 | **−** | 对等权市场回归的残差标准差，60 日，年化 |
| F8 | Amihud 非流动性 | **+** | `mean(\|ret\| / 成交额)`，60 日 |
| F10 | 隔夜/日内分解 | **+** | `Σ20(open/preclose-1) − Σ20(close/open-1)` |
| F11 | 低 beta | **−** | `-beta`（对等权市场，60 日） |
| F12 | 名义价格 | **+** | `1 / close` |

**F9 换手率（Miller 1977）已剔除** —— 见第二节的数据缺口。

### 不测的

日历效应、月份效应、任何需要参数搜索的形态。这类东西的数据挖掘风险
远大于其先验合理性。

## 四、网格与 N_trials

```
11 个因子  ×  2 种处理（原始 / 规模中性化）  ×  3 个持有期（5 / 20 / 60 日）
= 66 个配置（Stage A）
```

组合层网格（Stage B，只对通过 Stage A 的因子跑）：

```
3 持仓数（20/30/50） × 3 加权（等权/分数/风险平价） × 4 调仓周期（5/10/20/60 日）
× 2 缓冲带（开/关） = 72 个配置
```

**`N_trials` 不靠声称，靠测量。** 每一次回测（含被放弃的、跑错的、中途调参的）
都追加一行到 `analysis/factor_trials_log.csv`：

```
run_id, timestamp, config_hash, stage, IS_metric, OOS1_metric, note
```

**没有对应 log 行的结果不得进入报告。**

## 六、主指标与判定门槛

**Stage A 主指标 = 非重叠时点上的截面 Spearman IC。**

五个闸门，**全部在看结果之前定死**：

### 闸门 A｜符号
`sign(mean IC) == 预注册符号`。反了判 `无效`。
**不允许翻符号重报** —— 这一条专堵「反向使用」。

### 闸门 B｜显著性（多重检验校正）
- 族级 Bonferroni：`p < 0.05 / 66 = 7.58e-4`（等价 `|t| > 3.4`）
- 组合层 **Deflated Sharpe Ratio > 0.95**（Bailey & López de Prado），
  `n_trials` 取 `trials_log` 里的实际行数

### 闸门 C｜稳定性
- IS 内**至少 70% 的日历年** IC 同号
- IS 与 OOS-1 符号一致
- **留一年法**：逐年在 IS 内剔除一年重算，结论不得翻转

### 闸门 D｜经济性
多头最高分位组合在**基准成本模型（5bp 单边）后**：
- 超额年化 > 2%
- IR > 0.3
- **成本 / 毛利 < 0.5**

### 闸门 E｜可实施性
**T+1 开盘成交版本的超额 ≥ T 日收盘成交版本的 50%。**

否则说明 alpha 全在隔夜跳空里，**不可交易** → 判 `无效`。
（不是 `不具可比性`，是根本不能用。）

### 随机对照（必做）

用**同一套管线**跑 20 个随机截面分数，记录 IS 内 best-of-20 的 Sharpe 分布。
候选因子的 IS Sharpe 若落在该分布之内 → 判 `无效`。

这是对多重检验的**经验性校准**，成本极低，仓库从来没做过。

## 七、决策规则（写完不许改）

1. Stage A 只跑一次完整的 66 配置网格，全部记入 trials_log。
2. 只有**同时通过 A–E 五个闸门 + 随机对照**的因子进入 Stage B。
3. Stage B 按预注册规则选出**唯一**配置：在 IS 上最大化净 Sharpe；
   若两个配置差 < 0.1，**取调仓周期更长的那个**（交易更少 = 更稳健）。
4. 唯一配置写入 `portfolio/frozen.py`，**提交**，记录 `config_hash`。
5. 提交之后**恰好跑一次** OOS-2。看完不许改参数。
6. **若 0 个因子通过 Stage A → 直接跳收尾**（Stage 6）。
   严禁放宽阈值、严禁事后加因子、严禁改符号。

## 八、预期与可能代价（实验前填写）

| 项 | 内容 |
|---|---|
| **预期改善** | 若 F2（1 月反转）或 F6（MAX）成立，样本外年化超额 3–8% |
| **主指标** | 成本后组合净 Sharpe 与年化超额 |
| **可能代价** | 换手率上升带来的成本；小盘/低流动性暴露；回撤可能不改善 |
| **最可能的结果** | **全灭**。A 股价量因子的公开证据长期存在，任何存活下来的东西都必须扛住 66 次检验和 20 个随机对照 |
| **失败时的下一步** | 补基本面（价值/质量）—— **明确排除「再试更多 OHLCV 因子」** |

## 九、与既有 `StockPickingStrategy/` v1–v6 的可比性

**标为 `不具可比性`。** 那 6 个版本是「某个固定日期选一批股票、各持有
12 个月、算平均涨幅」——**没有调仓、没有成本、没有组合**，且只测了两段
重叠窗口，T1/T2/T3 行业分层就是在这两段窗口上事后归纳的。

口径（标的、调仓、成本、账户模型）全部不同，不得据此比较优劣。
