# v47 自适应做T数量

策略：`Stragety/MiniQMT_Stragety/DayT/DayT_v47_AdaptiveTSize.py`

本版本在v46多持仓、ATR重入和连接监控基础上新增按金额配置开仓数量，适用于主正T、主反T、MOM及阶梯追加开仓。

## 默认参数

v47文件开头可调整：

```python
T_TARGET_VALUE = 20000.0       # 每笔目标金额，非硬性资金上限
T_POSITION_FRACTION = 0.50    # 每笔使用未占用可卖底仓的比例
```

先从可卖底仓中扣除已被未完成正T/MOM正T占用的股份，得到可用于新做T的数量。然后分别计算金额对应的整手数量、持仓比例对应的整手数量，取两者与可用底仓的最小值。

金额不足一手时仍允许最小一手，因此400元股票可做100股、约4万元；2万元并非绝对上限。持仓比例不足一手、但仍有完整一手可用时，也允许这一手。这两个例外保证高价股及小底仓不会仅因预算或比例而完全停做T。

| 价格 | 未占用可卖底仓 | 默认新开数量 | 参考金额 |
|---:|---:|---:|---:|
| 65元 | 1000股 | 300股 | 19500元 |
| 65元 | 400股 | 200股 | 13000元 |
| 65元 | 200股 | 100股 | 6500元 |
| 400元 | 200股 | 100股 | 40000元 |
| 65元 | 100股 | 100股 | 6500元 |

这些是构造例子，不是读取实际账户得到的持仓。若长电实际只有200股可卖，默认仍做100股；只有底仓足够时才会扩大到多手。

## 资金与退出

- 新买入还受账户现金限制，预留1%金额余量，并扣除全部股票尚未完成的反T/MOM买回资金，包括本股票。
- 主反T与MOM新卖出不会占用已配对给正T的底仓。
- 资金不足目标手数时缩小到可承担的整手，不足最小一手则跳过。
- 自适应计算只用于新开仓。买回、卖回与强制退出均按现有交易腿记录的实际未平股数执行，不重新按2万元换算。
- 50%是每笔相对当前剩余可用底仓的比例，不是全天累计交易上限；原有交易次数限制继续生效。
- 最小交易单位沿用每个标的的配置：普通默认100股，688/689开头默认200股。特殊证券仍需人工配置，当前没有完整识别所有证券交易规则。

## 日志及运行

启动计划输出`T-SIZE PLAN`，实际触发时输出`T-SIZE`，包含目标金额、底仓比例、交易单位数、股数和估计金额。实际委托前再查仓位和现金，可能与启动计划不同。

```powershell
python run_bigqmt.py --strategy Stragety\MiniQMT_Stragety\DayT\DayT_v47_AdaptiveTSize.py --mode signal
```

信号模式只计算并打印计划；实盘使用`--mode live`。切换时不要让旧策略同时操作相同账户；旧进程未完成的交易状态不会自动迁移。

已完成6项离线功能测试，覆盖不同价位与底仓、现金限制、配对股份保留、自身买回资金保留、开仓增量与平仓数量分离、信号模式不下单。没有运行实际账户或收益回测；增加数量会同时放大盈亏。
