# v56 `ADVERSE_MOVE` 风险买回消融回测

## 结论

对当前实盘标的长电科技（600584）而言，现行 `max(1%, 0.1×ATR)` 风险买回在本次约一年、1分钟、严格连续账户回测中是**负收益贡献**：相对完全关闭该退出，账户净收益减少 4,966.70 元，最大回撤增加 0.329 个百分点，费用增加 206.70 元。

但不能直接删除该机制。关闭组最终仍有400股反T腿未买回、最长持续17个交易日；600105和601869关闭组也分别留下200股和400股未平腿。因此该机制对“恢复底仓、限制少持仓时间”有效，只是当前1%阈值对600584过紧。

> 后续决定：用户审阅结果后明确要求删除该机制。v56 已移除 `ADVERSE_MOVE` 分支，保留14:50时段退出和最大持有期退出；这属于用户风险偏好决策，不改变上述历史A/B结果及其限制。

## 方法

- 策略：`v56_nomom`
- 数据：本地前复权1分钟数据；过滤不足200根分钟线的不完整交易日
- 区间：600584、600105为2025-09-15至2026-09-11，共241日；601869为2025-09-09至2026-09-11，共243日
- 初始账户：现金100,000元，底仓1,000股
- 费用：买卖双边各0.05%
- A组：当前风险买回，阈值 `max(1%, 0.1×ATR)`
- B组：仅把最小不利阈值提高到1000%，保留其余信号、最大持有期和时段退出代码
- 评价：连续账户、T+1、逐事件成交；期末未平腿按末价计入权益，不当作已实现收益
