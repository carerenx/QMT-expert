# 长期v2核心＋确认反T卫星仓：实施与一年回测

## 实施范围

新建独立组合研究策略，不导入v55/v56同级策略文件。长期v2生成冻结的每日核心调仓计划，卫星模块只复用公共指标思想并独立实现确认反T。

- 强多头、熊市或非正常风险状态：T仓为0。
- 普通多头：T仓最多为实际持仓10%。
- 震荡：T仓最多为实际持仓20%。
- 正T关闭；每天最多一个反T。
- 3日收益为正或5日收益超过3%时禁止反T。
- 上涨达到`前收盘＋0.25ATR`后，要求峰值额外延伸0.15%、至少两个分钟事件、从峰值回落0.20%才卖出。
- 买回价差为`max(0.10ATR, 卖价1%)`；未达到则收盘强制买回，不跨日。
- 卫星仓不得突破冻结核心仓下限。

首版采用“冻结核心计划”模型：卫星盈亏进入真实现金和净值，但不反向修改已经由长期v2产生的核心信号。这用于隔离检验卫星T模块是否有独立增益，尚不是完整实盘耦合。

再次出现“高胜率但亏损”：长飞胜率75%，仍然亏损549.57元，因为一次-1,610.13元尾部亏损超过多笔小盈利。永鼎费用前已经亏损，说明不仅是手续费问题，卖出后的价格路径判断也不稳定。

## 安全验收

- 核心仓下限违规：三只均为0。
- 跨日未平仓卫星腿：三只均为0。
- 每日周期上限：1。
- 正T交易：0。
- 强多头和风险防守状态的新开反T：由预算函数阻止。
- 实盘入口：锁定。

## 结论

组合架构在账户隔离和安全性上成立，但收益假设没有通过：卫星反T没有稳定提高长期v2收益。当前版本标记为`RESEARCH_ONLY / REJECTED_FOR_RETURN_ENHANCEMENT`，不得因为长电+131.55元就认定有效。

若继续研究，优先处理尾部买回而不是提高交易频率：

1. 对收盘强制买回单独统计并限制亏损；最差周期表明尾部风险仍主导结果。
2. 将卫星比例再减半只能缩小盈亏，不能改变负期望，不能视为机制优化。
3. 下一候选应要求卖出后市场弱化确认，或在不利移动达到阈值时提前买回；必须使用新日期验证。
4. 组合策略没有必要进入全反馈耦合，除非冻结核心模型下卫星模块先取得跨标的正增益。
