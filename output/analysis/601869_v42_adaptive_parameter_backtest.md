## 结论

在本次样本和日线代理口径下，优先候选是仅修改：

```python
TRIGGER_TAIL_EXPONENT = 0.60
```

其余参数保持当前默认值。它的累计净收益代理为 **6.04%**，高于当前默认的 **4.33%**；触达后的次日不利率为 **27.3%**，低于默认的 **33.3%**。该结果样本量很小，只能作为下一轮 MiniQMT 仿真/小仓验证候选，不能当作收益保证。

## 数据与口径

- 标的：601869 长飞光纤。
- 数据：`data/optical_sector/kline_601869_长飞光纤.csv`，2025-12-10 至 2026-06-26，共 130 根日线。
- 滚动验证日：70 个。每个交易日仅使用该日开盘前的最近最多 80 根完成日线生成信号。
- 策略放行：复用 v42 的 `compute_signal`、自适应风格判断及 `do_short` 条件；bull 风格仍不放行反T。
- 触达：当日最高价达到当日开盘前计算的 `sell_trigger`。
- 回补代理：触达后，当日收盘价低于计划买回价，记为“日线同日回补代理”。日线没有盘中高低点先后顺序，**这不是成交确认**。
- 单次净收益估算：以计划卖出价、计划买回价、配置的佣金 `0.025%` 与印花税 `0.1%` 计算；未计滑点、最低佣金和未回补风险。
- 次日不利率：触达后下一个交易日收盘仍高于计划卖出价的比例，作为隔夜未回补风险的粗略代理。

## 解读

1. `ADAPTIVE_HISTORY_DAYS = 40` 不适合本轮目标。它提高了日线触达，但回补代理显著下降，且次日不利率升至 66.7%。
2. 降低 `TRIGGER_LOWER_BOUND_STRENGTH` 会抬高启动价，触达和累计收益代理均下降；当前 `1.0` 更合适。
3. `TRIGGER_TAIL_EXPONENT = 0.60` 将下尾分位取得更低，使启动价更靠近开盘价。样本内同时得到更多回补代理和更低的次日不利率，是本次唯一在收益、频率和风险代理三项上都优于默认的候选。
4. `STYLE_CONFIDENCE_MULTIPLIER = 1.20` 虽增加放行和触达，但次日不利率变高，不优先采用。

## 建议的下一步

先只将 `TRIGGER_TAIL_EXPONENT` 改为 `0.60`，其他默认参数不动。随后使用 1 分钟或 tick 数据复核“先触达卖出价、后到达买回价”的顺序，并计入最低佣金、滑点和未回补强制平仓，才可将日线代理结论升级为可执行收益结论。
