# 参数化单股长期持有策略 v1 实施与回测报告

## 实施结果

已完成独立于原做T系列的长期配置策略。策略只做多、不使用杠杆，每日收盘后使用完成日线形成计划，下一交易日09:40后执行；股票目标仓位限制在30%—100%，单次调整不超过账户权益的25%。

实现分为三个独立层次：

- `core/long_hold_allocation.py`：纯指标、市场状态、风险状态、目标仓位和整手订单计算；不依赖QMT。
- `LongHoldRotation_v1_TrendAllocation.py`：参数化单股研究入口，冻结次日计划并原子保存状态；实盘模式保持锁定。
- `backtest/long_hold_rotation.py`：通过BigQMT Redis RPC读取前复权日线与不复权1分钟线，模拟次日成交并生成双基准结果。

“兼容基准”保留10万元现金不动、只持有原始1000股；策略可以动用现金，因此容易超过这个基准。“公平基准”把相同初始总资产全部按整手买入股票后一直持有。两个标的都大幅落后公平基准，说明样本恰逢强上涨，主动降低仓位造成了显著机会成本。

## 验收失败原因

长电科技：

1. 实际CAGR 28.80%，低于30%目标；
2. 费用后落后公平全资金持有基准。

永鼎股份：

1. 最大回撤30.71%，超过30%硬上限；
2. 费用后落后公平全资金持有基准。

回测器已将这些规则写成机器可判定的`acceptance=FAIL`和`acceptance_failures`，不会因为绝对收益较高而误报通过。

## 策略机制

- 长期趋势：收盘价与MA120、MA60斜率。
- 中期趋势：MA20/MA60排列。
- 趋势效率：20日净位移除以累计绝对变化。
- 波动风险：ATR20与价格比率。
- 基础仓位：强多头75%、多头60%、震荡45%、熊市30%。
- 突破20日高点且趋势效率达标：提高一档。
- 长期趋势完整、回撤1.5ATR或2.5ATR后企稳：提高一档或两档。
- 高于MA20两倍ATR后转跌：降低一档。
- 跌破MA20且方向效率为负：降低一档；跌破MA60上限45%；确认熊市降至30%。
- 净值回撤20%降低一档；25%降至30%；30%禁止新增买入。
- 加仓至少间隔三个交易日；所有订单按100股整手并受现金约束。

## 限制与下一步

当前实现已经完成，但一年回测没有达到发布条件，实盘入口继续锁定。数据覆盖问题已经消除，失败来自收益、回撤和公平基准本身。

一年口径不再声称完成原计划中的12个月初始化/6个月样本外滚动。后续可按前6个月观察、后6个月冻结验证，并继续执行0.05%/0.08%/0.10%成本压力、1—3跳滑点和核心参数±20%扰动。只有CAGR、回撤、Calmar和公平持有超额同时满足，才允许进入模拟盘。
