# v53_nomom CycleRiskExit 优化验证

## 结论

基于 `v52_nomom` 在 2026-08-06 卖出后长期无法回补、连续账户只完成 4 个周期的问题，新建 `DayT_v53_nomom_CycleRiskExit.py`。新版本在保留 v52 周期所有权、检查点恢复和成交安全机制的基础上，为未完成 REV-T 周期增加有界风险退出。

本次改动显著减少了长期未回补风险，但仍未在该区间跑赢买入持有，因此状态为 **研究候选，不可用于实盘**。

## 风险退出规则

- 最长持有：3 个经行情数据验证的交易日。
- 逆向阈值：价格相对周期平均卖出价上涨达到 `max(3%, 0.75 × 开仓ATR)`。
- 任一条件满足后，通过周期所有权约束下的 `COMPETE` 回补委托退出。
- 未成交或部分成交时保留剩余周期、执行账本和策略腿；不伪造平仓。
- 退出完成后才允许新周期。
- 实盘入口继续禁用；状态文件独立使用 `v53_<account>.json`。

参数为事前风险约束，没有在本次样本中搜索最优组合。
