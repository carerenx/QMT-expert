## 结论

在相同的100,000元初始现金和200股底仓下，v53_nomom严格连续账户的期末总资产为186,444.47元，原版v39_nomom每日重启策略、连续账户的期末总资产为162,383.24元。v53最终多24,061.23元。

本次使用的是原版 `DayTradeing_v39_nomom.py`。此前设计的“复用正T信号恢复底仓”机制尚未写入新策略，因此不包含在本次结果中。

## v39账户连续性核验

逐日核对结果为0处断裂：下一交易日的期初现金等于上一交易日的期末现金，下一交易日的期初持仓也等于上一交易日的期末持仓。这里每日重置的只有策略实例，不是账户。

v39只有4个交易日产生成交：

8月6日两笔卖出后，策略以 `SOLD` 状态结束，但每日重启会丢弃这项内存状态。8月7日的新实例只能看到真实账户为0股；原版v39的正T买入容量又受可卖底仓约束，因此没有能力重新建立底仓，之后一直保持0股。

## 判断

本次对比中，v53收益更高。优势主要不是来自现金交易利润，而是v53最终仍持有200股，保留了87,148元期末股票市值；原版v39在8月6日之后完全空仓，错过了后续上涨。

这也意味着此前设计的底仓恢复买入机制必须新建版本并重新回测，才能判断它是否改善原版v39；不能将该机制视为已经包含在此次结果中。
