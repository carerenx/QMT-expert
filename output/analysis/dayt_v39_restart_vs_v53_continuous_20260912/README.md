## 原因分析

v39在8月3日至5日完成了若干做T，8月6日分两笔卖出全部200股，但当天没有买回。策略在次日重新创建后只看到真实账户持仓为0股，把0股作为新的执行基础，因此之后没有可用于反T或配对正T的底仓，直至回测结束都没有再成交。

v39虽然持有大量现金，但错过了股价从8月6日卖出区域上涨至9月10日435.74元的底仓升值。最终总资产因此比v53少24,061.23元。

v53连续保留未完成周期，并通过最长3个交易日和逆向ATR风险退出重新买回底仓。它完成28个周期，期末恢复为200股，因此保留了大部分上涨期间的底仓价值。其交易费用和最大回撤更高，但最终总资产仍明显高于v39每日重启方案。

## 结论

在“账户连续、只有v39策略每天重启”的可比口径下，**v53_nomom收益更高**：期末总资产多24,061.23元，账户净收益也多24,061.23元。

这项结果同时说明，每日重启策略不能安全替代跨日交易账本。策略内存可以重启，但未完成卖出腿的归属、目标和风险状态必须持久化或从可信成交账本恢复。
