## 判定

没有候选具备足够证据升级为通用优化。010平均改善约0.20个百分点，但主要来自立讯精密改善8.37个百分点；另仅中国石油、国电南瑞改善。恒瑞退步2.06个百分点、隆基退步1.47个百分点。此结果体现个别标的贡献集中，不能以平均值轻微上涨宣称普遍有效。
