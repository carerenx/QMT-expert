# v56 / v056 / v056(正T开启·无正T止损) 每日重置回测

## 结论

本报告每天重新初始化现金、1000股底仓、策略状态和周期账本，衡量单日独立启动表现。它不模拟跨日持仓、T+1延续、风险库存或恢复过程，因此不能替代严格连续账户报告。

三个口径中合计超额净收益最高的是 **v056 正T开启·无正T止损**（1,231.07 元），相对 v56 基准变化 4,851.70 元，相对 v056 正T冻结变化 2,245.29 元。

三者最差单日回撤相同，均为 10.10%；本样本内关闭正T止损没有改变最差单日回撤。

**收益质量是本报告最需要打折的地方。** 正T开启口径有 39 → 63 天的未闭合日，其中 25 天带着未平正T腿过夜，累计 3600 股、成本 887,534.00 元。在每日重置口径下这些腿被直接丢弃，既不计入次日的真实持仓，也没有为日末强制平仓支付手续费。若实盘在日末强制平掉这批腿，结果会因卖出时点和额外费用而改变。同时，正T把手续费从 3,632.22 元推高到 5,318.93 元，这部分是确定的成本。

正T腿已实现 16,119.00 元，但日末仍持有的正T腿浮亏 -13,259.00 元，把合计压到 2,860.00 元——已实现利润的 82% 被未平腿的浮动亏损抵消。**该通道的账面转正依赖未平仓腿的处置方式，本样本不足以支持"正T已经转正"的结论。**

600584 与 600105 在每日重置口径下三个版本均无成交，全部差异来自 601869，不具备跨标的一致性，不能据此推广到其他标的。

## 口径限制

- 每个交易日均以现金 100,000 元、底仓 1,000 股、全新策略状态重新开始；日与日之间不复投。
- 本地 1 分钟 K 线，区间 20250915至20260911；仅纳入至少 230 根分钟线且有 80 日历史的交易日。
- 每边费率 0.05%，无额外滑点；费用按成交额后处理扣除。
- `T_TARGET_VALUE=40,000`、`QUANTILE_UNITS_SCALE=1.0`，其余参数使用各策略当前值。
- `v056 正T冻结` 使用策略默认 `LONG_RESEARCH_DISABLED=True`；`v056 正T开启·无正T止损` 设为 `False` 并把 `STOP_LOSS_PCT` 置为 1.0，使 `price <= 均价×(1-STOP_LOSS_PCT)` 永不成立，即关闭正T止损。
- 关闭正T止损只解除 -1.5% 强制卖出；日末强制平仓由 `ENABLE_FORCE_CLOSE` 控制，本轮仍为 False，因此未平正T腿不会在日末卖出，只计入未闭合日。
- 最大回撤是所有独立交易日中最差的单日内回撤，不能与连续账户最大回撤直接比较。
- 日末未闭合腿不会带入次日；相关日单独计数，不能将其当成已经完成的策略收益。
