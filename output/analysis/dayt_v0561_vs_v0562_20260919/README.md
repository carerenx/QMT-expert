# v0561 / v0562 CoreT 精简版：每日重置回测与删层归因

## 结论

v0561 由 v056 删减而来，只保留反T/正T状态机、`compute_signal` 的触发价公式、整手仓位换算和成交流水记账；正T止损与日末强平一并删除。v0562 在 v0561 基础上恢复 ATR 再入场。每个交易日以现金 100,000 元、底仓 1,000 股和全新状态重新开始，不能闭合的腿留在当日、不跨日不带入。

三标的合计：**v0562（含 ATR 再入场）超额净收益 12,240.42 元**，是本次所有口径里最好的；v0561（不含）为 -2,266.31 元，恢复 ATR 再入场带来 14,506.73 元。

对照：v56 基准 4,125.62 元、v056 正T冻结 1,833.98 元、v056 正T开启·无正T止损 315.96 元。v0562 比 v56 基准高 8,114.80 元，成交 620 笔（反T 259 / 正T 361），手续费 10,408.58 元。

**为什么加回 ATR 再入场是对的。** 它在一个周期闭合后，用实际成交价而不是早盘开盘价重新锚定下一轮的卖出/买回触发价。删掉它等于让当天剩下的所有周期都套用早盘那个已经过时的触发价。阶梯显示这一层是单项影响最大的一步。

## 删层归因（累积阶梯）

阶梯各行是**累积**口径，每行只比上一行多关一层；差额即该层的贡献。最大正贡献是 **L4 +正T止损关闭（21,035.30 元）**，最大负贡献是 **L7 +ATR再入场移除（-14,506.73 元）**。各层方向相反、量级都很大，所以「删得越多」并不等于「越好」——这也是 v0562 只恢复 ATR 再入场、而没有把方向准入一并恢复的原因：后者删除后是负贡献，但不是最大负项，留待独立样本判断。

## 精简忠实性

把两个 CoreT 版本与阶梯对应行逐笔比对：

- **v0561 与 L7 逐笔完全一致**（872 笔 / 343 周期 / 超额 -2,266.31 元）——说明该版本恰好等于 v056 关掉对应层之后的行为，删减没有引入意外偏离。

- **v0562 与 L5 逐笔完全一致**（620 笔 / 253 周期 / 超额 12,240.42 元）——说明该版本恰好等于 v056 关掉对应层之后的行为，删减没有引入意外偏离。

两项都完全吻合，说明这次精简是**纯删层**：CoreT 的行为恰好等于 v056 关掉对应层之后的行为，实现本身没有引入任何意外偏离。所有差异都来自被删掉的机制。

## 已知代价

601869.SH 上 v0562 有 1/241 天全天零成交，反T成交 259 笔——删掉走势制度并没有把反T通道删死。但 v0562 的未闭合日（114 天）多于 v056 正T冻结（44 天）：因为删掉了正T止损和日末强平，这正是「能闭合则闭合，不能闭合则不闭合」的直接代价。这些日子按当日收盘价盯市计入超额收益，但没有为日末平仓支付手续费，也未计入次日真实持仓——收益质量仍需打折。

全部差异仍集中在 601869：600584 与 600105 在每日重置口径下各版本均无成交，不具备跨标的一致性，不能据此推广到其他标的。

## 口径限制

- 每个交易日均以现金 100,000 元、底仓 1,000 股、全新策略状态重新开始；日与日之间不复投。
- 本地 1 分钟 K 线，区间 20250915至20260911；仅纳入至少 230 根分钟线且有 80 日历史的交易日。
- 每边费率 0.05%，无额外滑点；费用按成交额后处理扣除。
- `T_TARGET_VALUE=40,000`、`T_POSITION_FRACTION=0.40`；v056 额外的 `QUANTILE_UNITS_SCALE=1.0`。
- v0561 不提供 `QUANTILE_UNITS_SCALE`／`DIRECTIONAL_*`／`INTRADAY_*` 等开关，传这些 override 会被拒绝——这正是精简的体现。
- v0561 **没有**正T止损（`STOP_LOSS_PCT` 分支已删）也**没有**日末强平，因此未闭合日会明显多于 v056。
- 每日重置口径丢弃日末未平腿。**不要**用严格连续账户口径给 v0561 打分：连续账户会保留这些腿的真实库存，而每日重置的状态机已经不再跟踪它们，连续回放度量的是那部分孤儿持仓而不是策略本身（实测最大回撤会退化到 54% 量级）。
- 最差单日回撤是所有独立交易日中最差的单日内回撤，不能与连续账户最大回撤比较。
