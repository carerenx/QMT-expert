因此本次最终排名为：v53第一，v40第二，原版v39第三。

## 策略改动

v40是从v39完整复制形成的新策略文件，没有导入同级旧策略。MOM继续关闭，仅增加底仓恢复机制：

1. 每日启动后，若真实持仓低于目标底仓200股，恢复通道独占交易权。
2. 使用原版正T的动态 `buy_trigger` 等待价格下探。
3. 价格触发后记录最低价，等待从低点反弹达到 `BOUNCE_PCT`。
4. 反弹确认后，按原版正T的 `COMPETE` 对手价方式买入缺失股数。
5. 成交股票直接补入底仓，不写入 `long_legs`，也不设置正T卖回目标。
6. 恢复完成当日关闭新开腿，次日再按正常v39逻辑运行。
7. 单日恢复委托上限为3笔；未成交不会伪造恢复成功。

QMT指定股数交易接口为 `order_shares(stockcode, shares[, style, price], ContextInfo[, accId])`；正股数表示买入，`COMPETE`为对手价。[Python API, p.101]

## 验收结果

- v39/v51黄金复现：通过，396次独立日运行的成交与盈亏完全一致。
- v40机制测试：3项通过，覆盖等待正T触发、等待反弹确认、恢复成交不写入普通多头腿。
- DayT测试：188项全部通过，黄金哈希通过。
- v40每日重启、连续账户回测：通过。
- v40严格连续账户验收：**无效**，错误为 `legacy daily reset would discard open execution legs at 20260807`。

严格连续验收失败的原因是：8月6日未平反T卖出腿仍会随v39式日重置丢失；v40在8月7日根据目标底仓缺口重新买入，而不是恢复原卖出腿的周期所有权。它符合本次指定的研究模型，但没有达到v53那种跨日成交账本和周期所有权标准。

因此v40当前只能作为“每日重启策略、账户连续”的研究版本，不能发布为严格连续或实盘策略。
